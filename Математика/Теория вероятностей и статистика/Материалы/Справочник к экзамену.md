# Часть I. Математическая статистика

## Билет 1. Предмет математической статистики

**Идеология.** Теория вероятностей и статистика решают обратные друг другу задачи. Теория вероятностей: распределение $\longrightarrow$ характеристики. Статистика: данные $\longrightarrow$ выводы о распределении.

В реальных задачах закон распределения генеральной совокупности неизвестен; его восстанавливают по конечной выборке.

**Генеральная совокупность** — все объекты, представляющие интерес. **Выборка** — конечный набор отобранных объектов; число элементов $n$ — **объём выборки**. Выборка **репрезентативна**, если по ней можно делать содержательные выводы о генеральной совокупности (большой объём репрезентативности не гарантирует).

**Типовые задачи статистики:** точечная оценка параметра; интервальная оценка; проверка гипотез (честна ли монета); выявление значимых факторов; оценка влияния воздействия.

## Билет 2. Модель простейшей выборки. Эмпирическая функция распределения

### Модель простейшей выборки

**Определение.** Простейшая выборка объёма $n$ — это набор **независимых одинаково распределённых** (i.i.d.) случайных величин $X_1, \dots, X_n$ с общей (неизвестной) функцией распределения

$$F(t) = P(X_k \le t).$$

Случайные величины $X_1,\dots,X_n$ — абстрактный объект; конкретные числа $x_1,\dots,x_n$ — **реализация** выборки.

### Эмпирическая функция распределения

**Определение.** Подсчётная функция $\mu_n(t) = \sum_{k=1}^n \mathbf{1}[X_k \le t]$ — число элементов выборки, не превосходящих $t$. **Эмпирическая функция распределения**

$$\hat F_n(t) = \frac{\mu_n(t)}{n} = \frac1n \sum_{k=1}^n \mathbf{1}[X_k \le t].$$

Это естественная частотная оценка: неизвестная вероятность $F(t)=P(X\le t)$ заменяется наблюдаемой долей. График $\hat F_n$ — ступенчатая функция со скачками в точках выборки величиной (число вхождений)$/n$.

### Распределение $\mu_n(t)$

Каждый индикатор $\mathbf{1}[X_k \le t] \sim \text{Ber}(F(t))$, индикаторы независимы, поэтому

$$\mu_n(t) \sim \text{Bin}(n,\, F(t)).$$

### Свойство 1 — несмещённость

$$\mathbb{E}[\hat F_n(t)] = \frac1n \mathbb{E}[\mu_n(t)] = \frac1n \cdot n F(t) = F(t).$$

То есть $\hat F_n(t)$ не имеет систематической ошибки.

### Свойство 2 — дисперсия

$$\mathrm{Var}(\hat F_n(t)) = \frac{1}{n^2}\mathrm{Var}(\mu_n(t)) = \frac{n F(t)(1-F(t))}{n^2} = \frac{F(t)(1-F(t))}{n}.$$

### Свойство 3 — состоятельность

По неравенству Чебышёва для любого $\varepsilon>0$:

$$P\big(|\hat F_n(t)-F(t)|>\varepsilon\big) \le \frac{\mathrm{Var}(\hat F_n(t))}{\varepsilon^2} = \frac{F(t)(1-F(t))}{n\varepsilon^2} \xrightarrow{n\to\infty} 0,$$

так как $F(t)(1-F(t))\le \tfrac14$ ограничено. По существу это ЗБЧ: $\hat F_n(t)$ — среднее i.i.d. бернуллиевских величин.

> **Несмещённость vs состоятельность.** Несмещённость верна при любом фиксированном $n$; состоятельность — асимптотическое свойство ($n\to\infty$). Одно не влечёт другое.

**Терминология оценок.** Оценка $\hat\theta$ **несмещённая**, если $\mathbb{E}[\hat\theta]=\theta$; **состоятельная**, если $\hat\theta_n \xrightarrow{P} \theta$.

## Билет 3. Начальные выборочные моменты. Выборочное среднее

**Определение.** **Начальный выборочный момент** порядка $k$:

$$\hat a_k = \frac1n \sum_{i=1}^n X_i^k.$$

При $k=1$ получаем **выборочное среднее** $\bar X = \tfrac1n \sum_{i=1}^n X_i$.

**Свойства $\bar X$ как оценки $\mathbb{E}[X]=a$** (при $\mathbb{E}[X]=a$, $\mathrm{Var}(X)=\sigma^2$):

- **Несмещённость:** $\displaystyle \mathbb{E}[\bar X] = \frac1n \sum_i \mathbb{E}[X_i] = a.$
- **Дисперсия:** $\displaystyle \mathrm{Var}(\bar X) = \frac{1}{n^2}\sum_i \mathrm{Var}(X_i) = \frac{\sigma^2}{n}$ (использована независимость).
- **Состоятельность:** $\mathrm{Var}(\bar X)\to 0$, поэтому по Чебышёву $\bar X \xrightarrow{P} a$ (ЗБЧ).

Аналогично $\hat a_k$ несмещён и состоятелен для теоретического момента $a_k = \mathbb{E}[X^k]$ (при его конечности): $\mathbb{E}[\hat a_k]=a_k$, и по ЗБЧ $\hat a_k \xrightarrow{P} a_k$.

## Билет 4. Центральные выборочные моменты. Выборочная и исправленная дисперсии

**Определение.** **Центральный выборочный момент** порядка $k$:

$$\hat\mu_k = \frac1n \sum_{i=1}^n (X_i - \bar X)^k.$$

При $k=2$ — **выборочная дисперсия**

$$S^2 = \frac1n \sum_{i=1}^n (X_i - \bar X)^2.$$

### Выборочная дисперсия смещена

**Утверждение.** $\displaystyle \mathbb{E}[S^2] = \frac{n-1}{n}\sigma^2 \neq \sigma^2.$

**Доказательство (схема).** Удобно использовать тождество $\sum_i (X_i-\bar X)^2 = \sum_i (X_i-a)^2 - n(\bar X - a)^2$, где $a=\mathbb{E}[X]$. Возьмём ожидание:

$$\mathbb{E}\Big[\sum_i (X_i-\bar X)^2\Big] = \sum_i \mathrm{Var}(X_i) - n\,\mathrm{Var}(\bar X) = n\sigma^2 - n\cdot\frac{\sigma^2}{n} = (n-1)\sigma^2.$$

Делим на $n$: $\mathbb{E}[S^2] = \tfrac{n-1}{n}\sigma^2$. Смещение возникает потому, что центрируем не на $a$, а на оценке $\bar X$ (теряется одна «степень свободы»). $\square$

### Исправленная (несмещённая) дисперсия

$$S_0^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i-\bar X)^2 = \frac{n}{n-1}S^2,\qquad \mathbb{E}[S_0^2] = \sigma^2.$$

Обе оценки состоятельны (множитель $\tfrac{n}{n-1}\to 1$).

## Билет 5. Вариационный ряд, квантили, медиана, мода

**Вариационный ряд:** упорядоченная реализация $x_{(1)}\le x_{(2)}\le\cdots\le x_{(n)}$. Элемент $X_{(k)}$ — **$k$-я порядковая статистика**; $X_{(1)}=\min$, $X_{(n)}=\max$.

**Выборочный квантиль** порядка $\alpha\in(0,1)$:

$$q_\alpha = x_{(\lfloor n\alpha\rfloor + 1)}.$$

Ниже $q_\alpha$ лежит доля $\approx\alpha$ наблюдений, выше — доля $\approx 1-\alpha$.

| Объект | Порядок | Смысл |
|---|---|---|
| Квартили $Q_k$ | $k/4$, $k=0,\dots,4$ | $Q_1,Q_2,Q_3$ — нижний, медиана, верхний |
| Перцентиль $x$ | $x/100$ | разбиение на 100 частей |
| Дециль $k$ | $k/10$ | разбиение на 10 частей |

**Межквартильный размах:** $\mathrm{IQR}=Q_3-Q_1$ — устойчивая к выбросам мера разброса.

**Выборочная медиана** — квантиль порядка $1/2$:

$$\mathrm{med} = \begin{cases} x_{((n+1)/2)}, & n=2k+1,\\[4pt] \tfrac12\big(x_{(n/2)}+x_{(n/2+1)}\big), & n=2k. \end{cases}$$

(первый случай — нечётный объём, второй — чётный).

**Выборочная мода** — наиболее часто встречающееся значение выборки (для непрерывных данных — центр самого «плотного» интервала гистограммы). Мод может быть несколько.

## Билет 6. Визуализация выборки

- **Полигон частот:** ломаная, соединяющая точки (значение; частота); для дискретных данных.
- **Гистограмма:** ось разбивается на интервалы (интервальный вариационный ряд), высота столбца — число или доля попавших элементов. Параметр `density` нормирует на долю (удобно сравнивать выборки разного объёма). Аппроксимирует функцию вероятности (дискретный случай) или плотность (непрерывный).
- **Box-plot (ящик с усами):** прямоугольник от $Q_1$ до $Q_3$, центральная линия — медиана $Q_2$; усы на расстоянии $1{,}5\cdot\mathrm{IQR}$ от квартилей; точки за усами — выбросы. Удобен для сравнения групп.
- **График $\hat F_n$:** ступенчатая неубывающая функция от $0$ до $1$ со скачками в точках выборки.

## Билет 7. Точечное оценивание: состоятельность, несмещённость, MSE

**Постановка.** Дана выборка $X_1,\dots,X_n$ из распределения с неизвестным параметром $\theta$. **Точечная оценка** — статистика $\hat\theta=\hat\theta(X_1,\dots,X_n)$, дающая одно число-приближение $\theta$.

**Несмещённость:** $\mathbb{E}[\hat\theta]=\theta$. **Смещение:** $\mathrm{bias}(\hat\theta)=\mathbb{E}[\hat\theta]-\theta$.

**Состоятельность:** $\hat\theta_n \xrightarrow{P}\theta$ при $n\to\infty$.

**Средняя квадратическая ошибка (MSE):**

$$\mathrm{MSE}(\hat\theta) = \mathbb{E}\big[(\hat\theta-\theta)^2\big].$$

### Разложение MSE на дисперсию и квадрат смещения

$$\mathrm{MSE}(\hat\theta) = \mathrm{Var}(\hat\theta) + \big(\mathrm{bias}(\hat\theta)\big)^2.$$

**Доказательство.** Обозначим $b=\mathbb{E}[\hat\theta]-\theta$. Тогда

$$\mathbb{E}[(\hat\theta-\theta)^2] = \mathbb{E}\big[(\hat\theta-\mathbb{E}\hat\theta + b)^2\big] = \mathbb{E}[(\hat\theta-\mathbb{E}\hat\theta)^2] + 2b\,\underbrace{\mathbb{E}[\hat\theta-\mathbb{E}\hat\theta]}_{=0} + b^2 = \mathrm{Var}(\hat\theta) + b^2. \quad\square$$

> **Связь со состоятельностью.** Если $\mathrm{MSE}(\hat\theta_n)\to 0$, то $\hat\theta_n\xrightarrow{L^2}\theta$, откуда (через Чебышёва) и $\hat\theta_n\xrightarrow{P}\theta$. Достаточно, чтобы и дисперсия, и смещение стремились к нулю.

## Билет 8. Метод моментов

**Идея.** Приравнять теоретические моменты к выборочным и решить относительно параметра.

**Алгоритм.** Для одного параметра $\theta$: выразить $\mathbb{E}[X]=g(\theta)$ через $\theta$; приравнять $g(\hat\theta)=\bar X$; решить. Для $r$ параметров берут первые $r$ моментов и решают систему.

**Пример ($\text{Bin}(m,p)$, $m$ известно).** $\mathbb{E}[X]=mp$, приравниваем $\bar X = m\hat p$:

$$\hat p_{MM} = \frac{\bar X}{m} = \frac{1}{nm}\sum_{i=1}^n X_i.$$

> Делить нужно на $m$ (параметр распределения), а не на $n$.

**Свойства.** Обычно прост; даёт состоятельные оценки (по ЗБЧ выборочные моменты сходятся к теоретическим, а $g^{-1}$ непрерывна); как правило, менее эффективен, чем ММП.

## Билет 9. Метод максимального правдоподобия (ММП)

**Идея.** Выбрать $\theta$, при котором наблюдаемая выборка наиболее правдоподобна.

**Алгоритм.**
1. Функция правдоподобия $L(\theta) = \prod_{i=1}^n p(X_i\mid\theta)$ (для дискретного случая — произведение вероятностей).
2. Лог-правдоподобие $\ell(\theta)=\ln L(\theta) = \sum_i \ln p(X_i\mid\theta)$.
3. Уравнение правдоподобия $\ell'(\theta)=0$, решить относительно $\theta$.

**Пример ($\text{Bin}(m,p)$).** $p(k\mid p)=\binom{m}{k}p^k(1-p)^{m-k}$, поэтому

$$\ell(p) = \mathrm{const} + \Big(\sum_i X_i\Big)\ln p + \Big(mn-\sum_i X_i\Big)\ln(1-p).$$

$$\ell'(p) = \frac{\sum_i X_i}{p} - \frac{mn-\sum_i X_i}{1-p} = 0 \;\Longrightarrow\; \hat p_{MLE} = \frac{\sum_i X_i}{mn} = \frac{\bar X}{m}.$$

Для $\text{Bin}(m,p)$ оценки совпадают: $\hat p_{MM}=\hat p_{MLE}=\bar X/m$.

| Критерий | Метод моментов | ММП |
|---|---|---|
| Идея | теор. момент = выборочному | максимум правдоподобия |
| Сложность | проще | сложнее (дифференцирование $\ell$) |
| Эффективность | ниже | выше (асимптотически оптимален) |

## Билет 10. Интервальное оценивание. Bootstrap

**Доверительный интервал** уровня $1-\alpha$ — пара статистик $(\hat L,\hat R)$ такая, что

$$P(\hat L \le \theta \le \hat R) \ge 1-\alpha.$$

Интерпретация: при многократном повторении эксперимента доля $\ge 1-\alpha$ построенных интервалов накрывает истинный $\theta$.

### Общая (асимптотическая) схема

Пусть $\sqrt n(\hat\theta-\theta)\xrightarrow{d} \mathcal{R}$ с функцией распределения $R$. Из

$$P\big(R^{-1}(\alpha/2) \le \sqrt n(\hat\theta-\theta) \le R^{-1}(1-\alpha/2)\big) \approx 1-\alpha$$

разрешением относительно $\theta$ получаем

$$\left[\hat\theta - \frac{R^{-1}(1-\alpha/2)}{\sqrt n},\;\; \hat\theta - \frac{R^{-1}(\alpha/2)}{\sqrt n}\right].$$

### Bootstrap (когда $R$ неизвестно)

1. По выборке построить эмпирическое распределение (или $\hat F_n$).
2. Сгенерировать $B$ псевдовыборок объёма $n$ (с возвращением).
3. Для каждой вычислить $\hat\theta^{*(b)}$.
4. **Пивотальная (центрированная) схема:** построить $z^{*(b)} = \sqrt n(\hat\theta^{*(b)} - \hat\theta)$ и взять её квантили $q^*_{\alpha/2}, q^*_{1-\alpha/2}$. Интервал:

$$\left[\hat\theta - \frac{q^*_{1-\alpha/2}}{\sqrt n},\;\; \hat\theta - \frac{q^*_{\alpha/2}}{\sqrt n}\right].$$

> Центрирование на $\hat\theta$ обязательно: оценивается распределение именно $\sqrt n(\hat\theta-\theta)$. Обе границы — это $\hat\theta$ минус квантиль$/\sqrt n$; слева вычитается **правый** квантиль, справа — **левый**.

## Билет 11. Проверка гипотез: общий принцип, p-value, ошибки I и II рода

**Гипотезы.** $H_0$ — «предположение по умолчанию» (нет эффекта, параметр равен типичному значению), $H_1$ — «подозрение» (то, что хотим обнаружить). Аналогия: презумпция невиновности ($H_0$) против обвинения ($H_1$).

> «Принять $H_0$» означает лишь «данные не противоречат $H_0$ при данной $H_1$», а не «$H_0$ доказана». Решение зависит от выбора $H_1$.

**Статистика критерия** $g(X)$ — функция от выборки с **известным при $H_0$** распределением. Пространство её значений делится на **область принятия** $T_0(\alpha)$ и **критическую область** $T_1(\alpha)$:

$$P(g(X)\in T_1 \mid H_0) = \alpha,\qquad P(g(X)\in T_0\mid H_0)=1-\alpha.$$

**Правило:** если $g_{\mathrm{obs}}\in T_1$ — отвергнуть $H_0$, иначе принять.

**Три типа критической области** (через квантили $z_q$ распределения $g$ при $H_0$):

| Тип | $T_1(\alpha)$ | для $H_1$ |
|---|---|---|
| Правосторонний | $(z_{1-\alpha},+\infty)$ | параметр больше |
| Левосторонний | $(-\infty, z_\alpha)$ | параметр меньше |
| Двусторонний | $(-\infty,z_{\alpha/2})\cup(z_{1-\alpha/2},+\infty)$ | параметр $\neq$ |

**p-value** — вероятность при истинной $H_0$ получить значение статистики, столь же или более экстремальное, чем $g_{\mathrm{obs}}$:

$$p_{\text{right}} = P(g> g_{\mathrm{obs}}\mid H_0),\quad p_{\text{left}} = P(g< g_{\mathrm{obs}}\mid H_0),\quad p_{\text{two}}=2\min(p_{\text{right}},p_{\text{left}}).$$

**Правило через p-value:** отвергнуть $H_0 \iff p\text{-value} < \alpha$.

**Эквивалентность** (правосторонний случай): $p_{\text{right}} = 1-F_0(g_{\mathrm{obs}}) < \alpha \iff F_0(g_{\mathrm{obs}}) > 1-\alpha \iff g_{\mathrm{obs}} > z_{1-\alpha} \iff g_{\mathrm{obs}}\in T_1$. Левосторонний и двусторонний — аналогично.

**Ошибки.**

| | $H_0$ верна | $H_0$ ложна |
|---|---|---|
| отвергли $H_0$ | ошибка I рода (вер. $\alpha$) | верно |
| приняли $H_0$ | верно | ошибка II рода (вер. $\beta$) |

Уровень значимости $\alpha$ контролирует ошибку I рода; **мощность** критерия $1-\beta$ — вероятность правильно отвергнуть ложную $H_0$.

> p-value — НЕ вероятность того, что $H_0$ верна. Это вероятность столь же экстремальных данных при условии $H_0$.

## Билет 12. Гипотезы о параметре: Бернулли, Пуассон, геометрическое

Общая идея для всех трёх: статистика $T=\sum_{i=1}^n X_i$ при $H_0$ имеет **известное точное распределение** (сумма независимых одинаковых величин), по которому строятся критические области и p-value.

### Бернулли $\text{Ber}(p)$

$H_0: p=p_0$. Статистика $T=\sum_i X_i \sim \text{Bin}(n, p_0)$ при $H_0$. (Если наблюдения — $\text{Bin}(m,p)$, то $T\sim\text{Bin}(mn,p_0)$.)

### Пуассон $\text{Pois}(\lambda)$

$H_0:\lambda=\lambda_0$. Сумма независимых пуассоновских величин снова пуассоновская:

$$T = \sum_{i=1}^n X_i \sim \text{Pois}(n\lambda_0)\quad (H_0).$$

Оценки: $\hat\lambda_{MM}=\hat\lambda_{MLE}=\bar X$ (так как $\mathbb{E}[X]=\lambda$).

### Геометрическое $\text{Geom}(p)$ (число испытаний до первого успеха, носитель $\{1,2,\dots\}$)

$\mathbb{E}[X]=1/p$, поэтому $\hat p_{MM}=1/\bar X$. $H_0: p=p_0$. Сумма $n$ независимых геометрических величин имеет **отрицательное биномиальное** распределение (число испытаний до $n$-го успеха):

$$T = \sum_{i=1}^n X_i \sim \text{NB}(n, p_0),\qquad P(T=t)=\binom{t-1}{n-1}(1-p_0)^{t-n}p_0^{\,n},\; t\ge n.$$

Это **точный** критерий — методологически корректный путь.

> **Важно (ловушка).** Нельзя проверять $H_0: p=\hat p_{MM}$ — такая гипотеза вырождена по построению (значение параметра берётся из тех же данных). $H_0$ должна задавать фиксированное $p_0$ извне.
>
> Вальдовский/Z-критерий через нормальную аппроксимацию требует дельта-метода (для перехода от $\bar X$ к $1/\bar X$) и в курс не входит — используем точный критерий через $\text{NB}$.

### Единая схема критических областей

Пусть $F_0$ — функция распределения $T$ при $H_0$ (соответственно $\text{Bin}$, $\text{Pois}$ или $\text{NB}$), $q_\gamma$ — её квантили:

| Альтернатива | Критическая область | p-value |
|---|---|---|
| $\theta\neq\theta_0$ | $T<q_{\alpha/2}$ или $T>q_{1-\alpha/2}$ | $2\min\big(F_0(T_{\mathrm{obs}}),\,1-F_0(T_{\mathrm{obs}}-1)\big)$ |
| $\theta>\theta_0$ | $T>q_{1-\alpha}$ | $1-F_0(T_{\mathrm{obs}}-1)$ |
| $\theta<\theta_0$ | $T<q_\alpha$ | $F_0(T_{\mathrm{obs}})$ |

(Для геометрического «большое $T$» отвечает «маленькому $p$», поскольку $\mathbb{E}[T]=n/p$ — учитывайте направление при сопоставлении альтернативы с хвостом.)

---

## Билет 13. Точный критерий Фишера (независимость в таблице сопряжённости)

**Задача.** Проверить независимость двух категориальных признаков по таблице $2\times2$ (строки — признак $A$, столбцы — признак $B$):

|  | $B_1$ | $B_2$ | итог |
|---|---|---|---|
| $A_1$ | $a$ | $b$ | $a+b$ |
| $A_2$ | $c$ | $d$ | $c+d$ |
| итог | $a+c$ | $b+d$ | $n$ |

$H_0$: признаки независимы; $H_1$: зависимы.

**Ключевая идея.** Зафиксируем все маргинальные суммы (итоги по строкам и столбцам). Тогда при $H_0$ число $a$ в верхней левой клетке имеет **гипергеометрическое** распределение, и вероятность конкретной таблицы зависит только от $a$:

$$P(a) = \frac{(a+b)!\,(c+d)!\,(a+c)!\,(b+d)!}{n!\;a!\;b!\;c!\;d!}.$$

**Вывод формулы (кратко).** При фиксированных маргиналиях таблица полностью определяется числом $a$. Из $a+c$ объектов столбца $B_1$ выбираем, сколько попадёт в строку $A_1$ — это гипергеометрическая модель «выбор без возвращения». Перебор разбиений с учётом полиномиальных коэффициентов и нормировки на $\binom{n}{a+b}$ даёт формулу выше. $\square$

**p-value.** Суммируем вероятности всех допустимых значений $a'$ (при тех же маргиналиях), которые не более вероятны, чем наблюдаемое:

$$p = \sum_{a':\; P(a')\le P(a_{\mathrm{obs}})} P(a').$$

(Для односторонней альтернативы суммируют только хвост в нужную сторону по $a$.) Если $p<\alpha$ — отвергаем независимость.

**Особенности.** Критерий **точный** (не асимптотический), пригоден для малых выборок, где $\chi^2$-критерий ненадёжен.

# Часть II. Цепи Маркова

## Билет 14. Дискретная цепь Маркова. Матрица перехода. Распределение в момент $n$

**Определение.** Последовательность $\{X_n\}_{n\ge0}$ со значениями в не более чем счётном множестве $E$ — **цепь Маркова**, если выполнено **марковское свойство**:

$$P(X_{n+1}=j \mid X_n=i_n,\dots,X_0=i_0) = P(X_{n+1}=j\mid X_n=i_n).$$

«Будущее зависит только от настоящего». $E$ — **пространство состояний**.

**Переходная матрица** на шаге $n$: $P_n=(p_{ij}(n))$, где $p_{ij}(n)=P(X_n=j\mid X_{n-1}=i)$. Она **стохастическая**:

$$\sum_{j\in E} p_{ij}(n) = 1,\qquad p_{ij}(n)\ge 0$$

(сумма по строке есть $P(X_n\in E\mid X_{n-1}=i)=1$).

**Вектор распределения** $\mathbf p(n) = (P(X_n=1), P(X_n=2),\dots)^\top$.

**Рекуррентная формула.** По формуле полной вероятности:

$$P(X_n=j) = \sum_i P(X_n=j\mid X_{n-1}=i)P(X_{n-1}=i) = \sum_i p_{ij}(n)\,p_i(n-1),$$

что есть $j$-я компонента вектора $P_n^\top \mathbf p(n-1)$. Значит,

$$\mathbf p(n) = P_n^\top\, \mathbf p(n-1).$$

---

## Билет 15. Однородные цепи Маркова

**Определение.** Цепь **однородна**, если $P_n=P$ не зависит от $n$. Тогда

$$\mathbf p(n) = P^\top \mathbf p(n-1) = (P^\top)^n\, \mathbf p(0).$$

Вся динамика закодирована в одной матрице $P$; задача сводится к возведению её в степень (спектральная теория). Однородную цепь изображают **взвешенным ориентированным графом**: ребро $i\to j$ с весом $p_{ij}$ существует $\iff p_{ij}>0$.

**Пример (диагонализация).** Если $P^\top = T\Lambda T^{-1}$, то $(P^\top)^n = T\Lambda^n T^{-1}$. Компоненты, отвечающие $|\lambda|<1$, затухают; компонента при $\lambda=1$ даёт предельное (стационарное) распределение.

---

## Билет 16. Формула Колмогорова–Чепмена

Обозначим $p_{ij}^{(n)} = P(X_n=j\mid X_0=i)$ — вероятность перехода $i\to j$ за $n$ шагов. Тогда $(P^n)_{ij}=p_{ij}^{(n)}$ (индукция по $n$).

**Теорема (Колмогоров–Чепмен).** Для любых $n,m\ge 0$:

$$p_{ij}^{(n+m)} = \sum_{k\in E} p_{ik}^{(n)}\, p_{kj}^{(m)}.$$

**Доказательство.** Из тождества $P^{n+m}=P^n P^m$ по определению матричного умножения:

$$(P^{n+m})_{ij} = \sum_k (P^n)_{ik}(P^m)_{kj} = \sum_k p_{ik}^{(n)}p_{kj}^{(m)}. \quad\square$$

Смысл: чтобы попасть из $i$ в $j$ за $n+m$ шагов, надо через $n$ шагов оказаться в некотором промежуточном $k$; суммируем по всем $k$.

---

## Билет 17. Классификация состояний. Структура матрицы перехода

**Достижимость:** $i\to j$, если $\exists\, n\ge1:\ p_{ij}^{(n)}>0$ (есть путь по графу). **Сообщаемость:** $i\leftrightarrow j$, если $i\to j$ и $j\to i$. Сообщаемость — отношение эквивалентности; состояния разбиваются на **классы**.

**Замкнутый класс:** из него нельзя уйти ($i\in C,\ i\to j\Rightarrow j\in C$). **Открытый:** можно уйти. **Поглощающее состояние:** замкнутый класс из одного состояния, $p_{ii}=1$.

**Существенные / несущественные.** $i$ **несущественно**, если $\exists j: i\to j$, но $j\not\to i$ (можно уйти навсегда). Иначе — **существенно**.

**Периодичность.** Период $d_i = \gcd\{n\ge1: p_{ii}^{(n)}>0\}$. Если $d_i=1$ — **апериодическое** состояние, иначе **периодическое** с периодом $d_i$.

**Возвратность.** $f_{ii}^{(n)}$ — вероятность **первого** возврата в $i$ за $n$ шагов; $f_{ii}=\sum_{n\ge1} f_{ii}^{(n)}$. Состояние **возвратно**, если $f_{ii}=1$; **невозвратно** (транзиентно), если $f_{ii}<1$.

**Нулевые.** $i$ **нулевое**, если $p_{ii}^{(n)}\to 0$; иначе **ненулевое**.

**Блочная структура.** Перенумеровав состояния (сначала открытый класс, затем замкнутые $C_1,\dots,C_r$), получаем

$$P = \begin{pmatrix} Q & R_1 & \cdots & R_r \\ 0 & P_1 & & \\ \vdots & & \ddots & \\ 0 & & & P_r \end{pmatrix},$$

где $Q$ — переходы внутри открытого класса, $P_k$ — внутри замкнутых, нули отражают невозможность вернуться из замкнутого класса.

---

## Билет 18. Связь между состояниями (конечные и счётные цепи)

### Критерий возвратности

**Теорема.** $i$ возвратно $\iff \displaystyle\sum_{n=1}^\infty p_{ii}^{(n)} = +\infty$.

**Доказательство.** Введём производящие функции $W(z)=\sum_{n\ge0}p_{ii}^{(n)}z^n$ ($p_{ii}^{(0)}=1$) и $U(z)=\sum_{n\ge0}f_{ii}^{(n)}z^n$ ($f_{ii}^{(0)}=0$). Разложение пути по моменту первого возврата даёт

$$p_{ii}^{(n)} = \sum_{k=1}^n f_{ii}^{(k)} p_{ii}^{(n-k)}\quad(n\ge1)\;\Longrightarrow\; W(z)-1 = U(z)W(z).$$

Отсюда $U(z) = 1 - \tfrac{1}{W(z)}$. Подставим $z\nearrow 1$: $f_{ii}=U(1)=1-\tfrac1{W(1)}$, где $W(1)=1+\sum_{n\ge1}p_{ii}^{(n)}$. Если ряд расходится, $W(1)=\infty$ и $f_{ii}=1$ (возвратно); если сходится, $f_{ii}<1$ (невозвратно). $\square$

### Цепочка импликаций (общие цепи)

Цепочка импликаций для общих цепей: несущественное $\Rightarrow$ невозвратное $\Rightarrow$ нулевое; контрапозитивно — ненулевое $\Rightarrow$ возвратное $\Rightarrow$ существенное. (Невозвратное $\Rightarrow$ ряд сходится $\Rightarrow p_{ii}^{(n)}\to0$, т.е. нулевое.)

### Теорема солидарности (для неразложимых цепей)

Если все состояния сообщаются, то возвратность, нулевость и период — **общие** для всех состояний. Идея: для $i\leftrightarrow j$ есть $m,l$ с $p_{ij}^{(m)}>0$, $p_{ji}^{(l)}>0$, и $p_{jj}^{(l+n+m)}\ge p_{ji}^{(l)}p_{ii}^{(n)}p_{ij}^{(m)}$; расходимость ряда для $i$ влечёт расходимость для $j$.

### Конечные цепи

В **конечной неразложимой** цепи все состояния ненулевые (а значит возвратные и существенные). Для конечных цепей понятия «существенное», «возвратное», «ненулевое» равносильны.

## Билет 19. Стационарное распределение. Среднее время первого возврата

**Определение.** Вектор $\boldsymbol\pi=(\pi_i)$, $\pi_i\ge0$, $\sum_i\pi_i=1$, — **стационарное распределение**, если

$$P^\top\boldsymbol\pi = \boldsymbol\pi,$$

т.е. $\boldsymbol\pi$ — собственный вектор $P^\top$ при $\lambda=1$. Если $\mathbf p(0)=\boldsymbol\pi$, то $\mathbf p(n)=\boldsymbol\pi$ для всех $n$.

**Существование (конечный случай).** У любой конечной цепи есть хотя бы одно стационарное распределение. Идея: $P^\top$ имеет собственное значение $1$ (так как у стохастической $P$ вектор из единиц — правый собственный при $\lambda=1$), а теорема Перрона–Фробениуса/Брауэра даёт неотрицательный нормированный собственный вектор.

**Практика.** $\boldsymbol\pi$ ищут из системы $(P^\top - E)\boldsymbol\pi=0$ с условием нормировки $\sum_i\pi_i=1$.

### Среднее время первого возврата

$\tau_i=\min\{n\ge1: X_n=i\}$, $\mu_{ij}=\mathbb{E}[\tau_j\mid X_0=i]$; при $i=j$ — среднее время возврата $\mu_{ii}$.

**Теорема.** Для эргодической цепи $\displaystyle \mu_{ii} = \frac{1}{\pi_i}$.

**Доказательство.** Рекуррентность по первому шагу: $\mu_{ij}=\sum_{k\neq j}p_{ik}(\mu_{kj}+1)+p_{ij}$. Умножим на $\pi_i$, просуммируем по $i$ и применим стационарность $\sum_i\pi_i p_{ik}=\pi_k$:

$$\sum_i\pi_i\mu_{ij} = \sum_{k\neq j}\pi_k\mu_{kj} + \sum_{k\neq j}\pi_k + \pi_j.$$

Сократив $\sum_{k\neq j}\pi_k\mu_{kj}$ с обеих сторон, получаем $\pi_j\mu_{jj}=\sum_k\pi_k=1$, откуда $\mu_{jj}=1/\pi_j$. $\square$

Смысл: чем больше доля $\pi_i$, тем чаще цепь в $i$ и тем короче ожидание возврата.

## Билет 20. Эргодические и сильно эргодические цепи. Критерии. Эргодическая теорема

**Эргодическая цепь** — существует единственное стационарное распределение $\boldsymbol\pi$.

**Сильно эргодическая** — существует предел, не зависящий от старта:

$$\lim_{n\to\infty} p_{ij}^{(n)} = \pi_j^* > 0\quad \forall i,j,\qquad \boldsymbol\pi^*=\boldsymbol\pi.$$

**Критерии сильной эргодичности (без доказательства).**

- **(а)** Конечная цепь сильно эргодична $\iff$ она неразложима и апериодична.
- **(б)** $\iff \exists n_0:\ p_{ij}^{(n_0)}>0$ для всех $i,j$ (матрица $P^{n_0}$ строго положительна) — самый удобный для проверки.
- **(в)** Счётная цепь сильно эргодична, если неразложима, апериодична и все состояния ненулевые.
- **(г)** $\iff$ цепь апериодична и эргодична (единственное $\boldsymbol\pi$ с $\pi_j>0$).

Если состояние нулевое, то $\pi_i=0$.

**Эргодическая теорема (без доказательства).** Для эргодической цепи, при $V_i(N)=\sum_{k=1}^N\mathbf{1}[X_k=i]$ (число посещений $i$ за время $N$):

$$P\Big(\lim_{N\to\infty}\frac{V_i(N)}{N}=\pi_i\Big)=1.$$

То есть $\pi_i$ — доля времени, проводимого в состоянии $i$ на длинном горизонте (аналог ЗБЧ для цепей).

---

## Билет 21. Поглощающие состояния. Фундаментальная матрица и её свойства

**Блочная форма при наличии поглощающих состояний** (транзиентные, затем поглощающие):

$$P = \begin{pmatrix} Q & R \\ 0 & E \end{pmatrix},$$

$Q$ ($m\times m$) — переходы между транзиентными, $R$ ($m\times l$) — из транзиентных в поглощающие.

### Степени $P$

По индукции

$$P^n = \begin{pmatrix} Q^n & (E+Q+\cdots+Q^{n-1})R \\ 0 & E \end{pmatrix}.$$

Поскольку поглощение происходит с вероятностью $1$, $Q^n\to 0$, ряд $E+Q+Q^2+\cdots$ сходится, и $E-Q$ обратима.

### Определение фундаментальной матрицы

$$N = E+Q+Q^2+\cdots = (E-Q)^{-1}.$$

### Свойство 1 — смысл элементов

**$N_{ij}$ — среднее число посещений транзиентного состояния $j$ до поглощения при старте из $i$.**

**Доказательство.** Пусть $\nu_j=\mathbf{1}[X_0=j]+\sum_{n\ge1}\mathbf{1}[X_n=j]$ при $X_0=i$. Тогда

$$\mathbb{E}[\nu_j\mid X_0=i] = \delta_{ij} + \sum_{n\ge1} P(X_n=j\mid X_0=i) = \delta_{ij}+\sum_{n\ge1}(Q^n)_{ij} = (E+Q+Q^2+\cdots)_{ij}=N_{ij}. \quad\square$$

### Свойство 2 — среднее число шагов до поглощения

Пусть $\mathbf t=(1,\dots,1)^\top$. Тогда $(N\mathbf t)_i = \sum_j N_{ij}$ — **среднее число шагов до поглощения** при старте из $i$ (сумма средних чисел посещений всех транзиентных состояний). $\square$

### Свойство 3 — матрица вероятностей поглощения

$$B = NR,\qquad B_{ij} = P(X_\infty = j \mid X_0=i),$$

где $B_{ij}$ — вероятность поглощения именно в состоянии $j$ при старте из транзиентного $i$.

**Доказательство.** В $P^n$ блок переходов «транзиентные $\to$ поглощающие» равен $(E+Q+\cdots+Q^{n-1})R \to NR$ при $n\to\infty$. Это и есть итоговая вероятность поглощения. Размерности: $N$ ($m\times m$), $R$ ($m\times l$), $B=NR$ ($m\times l$). При гарантированном поглощении строки $B$ суммируются в $1$. $\square$

### Стационарное распределение при поглощении

Сосредоточено на поглощающих состояниях: $\pi_i=0$ для всех транзиентных $i$, а на поглощающих — любое распределение, согласованное с нормировкой. Интуитивно: при $t\to\infty$ цепь всегда в поглощающем множестве.

> При составлении системы для $\boldsymbol\pi$ помните: $P^\top\boldsymbol\pi=\boldsymbol\pi \iff (P^\top-E)\boldsymbol\pi=0$. Не путайте $\boldsymbol\pi$ с вероятностями поглощения $B$.

## Билет 22. Приложения цепей Маркова. Генерация случайных величин (MCMC, Метрополис–Гастингс)

### Зачем

Часто нужно сэмплировать из сложного распределения $\pi$ (например, апостериорного в байесовской статистике), которое известно лишь с точностью до нормирующей константы. Идея MCMC: построить цепь Маркова, **стационарное распределение которой равно $\pi$**; запустив её надолго, получаем выборку из $\pi$ (по эргодической теореме — и оценки средних).

### Краткий обзор приложений

- **PageRank:** ранжирование веб-страниц = стационарное распределение цепи на графе ссылок.
- **Скрытые марковские модели (HMM):** распознавание речи, биоинформатика.
- **Теория массового обслуживания:** очереди, модели рождения–гибели.
- **MCMC (метод Монте-Карло по Маркову):** численное интегрирование, сэмплирование.

### Условие баланса

Если цепь удовлетворяет **детальному балансу** относительно $\pi$:

$$\pi_i\, p_{ij} = \pi_j\, p_{ji}\quad \forall i,j,$$

то $\pi$ — стационарное распределение (суммируя по $i$: $\sum_i\pi_i p_{ij}=\pi_j\sum_i p_{ji}=\pi_j$). Алгоритм Метрополиса–Гастингса конструирует переходы так, чтобы детальный баланс выполнялся автоматически.

### Алгоритм Метрополиса–Гастингса (полностью, без доказательства)

Цель — сэмплировать из $\pi$, известного с точностью до константы (нужны лишь отношения $\pi_j/\pi_i$). Задаётся **предложение** (proposal) $q(j\mid i)$ — вспомогательная переходная вероятность, из которой легко генерировать.

1. Инициализация: выбрать начальное состояние $X_0$.
2. На шаге $n$ (текущее состояние $i=X_n$):
   - сгенерировать кандидата $j \sim q(\cdot\mid i)$;
   - вычислить **коэффициент принятия**
   $$\alpha(i,j) = \min\!\left(1,\; \frac{\pi_j\, q(i\mid j)}{\pi_i\, q(j\mid i)}\right);$$
   - сгенерировать $u\sim \text{Uniform}(0,1)$;
   - если $u\le\alpha(i,j)$ — **принять**: $X_{n+1}=j$; иначе **отклонить**: $X_{n+1}=i$.
3. Повторять; после «прогрева» (burn-in) собранные $X_n$ считать выборкой из $\pi$.

**Замечания.**
- В формулу входит только отношение $\pi_j/\pi_i$ — нормирующая константа не нужна.
- При **симметричном** предложении $q(j\mid i)=q(i\mid j)$ (алгоритм Метрополиса) коэффициент упрощается до $\alpha=\min(1, \pi_j/\pi_i)$.
- Построенная цепь по конструкции удовлетворяет детальному балансу относительно $\pi$, поэтому $\pi$ — её стационарное распределение; при эргодичности распределение $X_n$ сходится к $\pi$.
- **Семплер Гиббса** — частный случай: кандидат берётся из условных распределений, и принятие всегда происходит ($\alpha=1$).
