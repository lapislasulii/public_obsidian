# КР №1 — шпаргалка must-have

## 1. Одномерное абсолютно непрерывное распределение

**Плотность и функция распределения**
- $f(x)\ge0$, $\displaystyle\int_{-\infty}^{\infty}f=1$ — отсюда находят $c$.
- $F(x)=\displaystyle\int_{-\infty}^{x}f(t)\,dt$, на практике нижний предел — **левый край носителя**, а не $-\infty$.
- $F$ — **функция**, а не число: выписывать кусочно (до носителя $0$, на носителе формула, после $1$).
- $\mathrm P(a<X<b)=F(b)-F(a)=\int_a^b f$; $\mathrm P(X=a)=0$.
- $f=F'$ (где производная существует).

**Моменты**
- $\mathrm EX=\int xf(x)\,dx$, $\mathrm E g(X)=\int g(x)f(x)\,dx$.
- $\mathrm{Var}X=\mathrm EX^2-(\mathrm EX)^2$.
- Существование: момент есть, если интеграл сходится **абсолютно**. Для хвоста $f\sim C/x^{\alpha}$: $\mathrm E|X|^k<\infty \iff \alpha-k>1$.
- Асимметрия: $\gamma=\dfrac{\mathrm E(X-\mu)^3}{\sigma^3}$.
- Симметрия относительно $a$ ⇒ $\mathrm EX=a$ **только если** $\mathrm EX$ существует (Коши — контрпример).

**Мода, медиана, квантили**
- Мода — максимум **$f$** (не $F$!): $f'=0$, точки излома, концы носителя.
- Медиана: $F(m)=\tfrac12$. Квантиль уровня $p$: $F(x_p)=p$.

**Основные распределения**

| Распределение | $f(x)$ | $\mathrm E$ | $\mathrm{Var}$ |
|---|---|---|---|
| $U[a,b]$ | $\frac1{b-a}$ на $[a,b]$ | $\frac{a+b}2$ | $\frac{(b-a)^2}{12}$ |
| $\mathrm{Exp}(\lambda)$ | $\lambda e^{-\lambda x}$, $x\ge0$ | $\frac1\lambda$ | $\frac1{\lambda^2}$ |
| $\Gamma(k,\lambda)$ | $\frac{\lambda^k x^{k-1}e^{-\lambda x}}{\Gamma(k)}$ | $\frac k\lambda$ | $\frac k{\lambda^2}$ |
| Парето | $\frac{\alpha x_m^\alpha}{x^{\alpha+1}}$, $x\ge x_m$ | $\frac{\alpha x_m}{\alpha-1}$ ($\alpha>1$) | есть при $\alpha>2$ |
| $N(\mu,\sigma^2)$ | $\frac1{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ |

- Для $U[a,b]$: $F(x)=\frac{x-a}{b-a}$ на $[a,b]$. Для $\mathrm{Exp}$: $F=1-e^{-\lambda x}$.
- Полезные интегралы: $\int_0^\infty x^n e^{-\lambda x}dx=\frac{n!}{\lambda^{n+1}}$; $\int_0^1 x^a(1-x)^b dx=\frac{a!\,b!}{(a+b+1)!}$.

## 2. Нормальное распределение

- Стандартизация: $X\sim N(\mu,\sigma^2)\Rightarrow Z=\frac{X-\mu}\sigma\sim N(0,1)$,
  $\mathrm P(a<X<b)=\Phi\!\left(\frac{b-\mu}\sigma\right)-\Phi\!\left(\frac{a-\mu}\sigma\right)$.
- $\Phi(-x)=1-\Phi(x)$ (таблица только для $x\ge0$).
- $\mathrm P(|X-\mu|<k\sigma)=2\Phi(k)-1$; правило $3\sigma$: $68\%/95\%/99.7\%$.
- **$\mathrm P(X>t)=1-\Phi(\cdot)$** — не забывать дополнение.
- Квантили $z_p$ ($\Phi(z_p)=p$): $0.90\to1.282$, $0.95\to1.645$, $0.975\to1.96$, $0.99\to2.326$, $0.995\to2.576$.
- Обратная задача (найти $t$ по вероятности): $t=\mu+\sigma z_p$.
- Гауссов интеграл: $\int_{-\infty}^\infty e^{-x^2/2}dx=\sqrt{2\pi}$; $\int_a^b e^{-x^2/2}dx=\sqrt{2\pi}\,(\Phi(b)-\Phi(a))$.
- Линейность: $aX+b\sim N(a\mu+b,\,a^2\sigma^2)$.
- Сумма независимых (или компонент гауссовского вектора): $aX+bY\sim N\big(a\mu_X+b\mu_Y,\ a^2\sigma_X^2+b^2\sigma_Y^2+2ab\,\mathrm{Cov}(X,Y)\big)$.
- Гауссовский вектор: **любая** линейная комбинация нормальна. Нормальные маргиналы ≠ гауссовский вектор (контрпример $Y=SX$, $S=\pm1$). Для гауссовского вектора некоррелированность ⇔ независимость.
- Условное распределение (двумерный гауссовский):
  $Y\mid X=x\sim N\!\left(\mu_Y+\rho\frac{\sigma_Y}{\sigma_X}(x-\mu_X),\ \sigma_Y^2(1-\rho^2)\right)$.
- Калькулятор fx-991ES: MODE → STAT → 1-VAR, затем SHIFT 1 → Distr → `P(` = $\Phi$ для стандартизованного аргумента; `R(t)` = $1-\Phi$.

## 3. Совместные абсолютно непрерывные распределения

- **Сначала рисунок носителя** — из него все пределы.
- Нормировка: $\iint f(x,y)\,dx\,dy=1$.
- Фубини: внешний интеграл — числа, **внутренний — пределы зависят от внешней переменной**. Пример: $0\le y\le x\le1$ ⇒ $\int_0^1\!\int_0^x$ (или $\int_0^1\!\int_y^1$).
- Маргинальные: $f_X(x)=\int f(x,y)\,dy$ (интегрируем по $y$ **в пределах носителя при данном $x$**).
- Условная: $f(y\mid x)=\dfrac{f(x,y)}{f_X(x)}$ — плотность по $y$, интеграл по $y$ равен 1 (проверка!).
- Условные моменты: $\mathrm E(Y\mid x)=\int y f(y\mid x)dy$, $\mathrm{Var}(Y\mid x)=\mathrm E(Y^2\mid x)-\mathrm E(Y\mid x)^2$.
- Полное матожидание: $\mathrm EY=\mathrm E\big[\mathrm E(Y\mid X)\big]$.
- $\mathrm E(XY)=\iint xy\,f\,dx\,dy$ (с **теми же** пределами носителя).
- $\mathrm{Cov}=\mathrm E(XY)-\mathrm EX\,\mathrm EY$, $\rho=\dfrac{\mathrm{Cov}}{\sigma_X\sigma_Y}$ (делим!), $|\rho|\le1$.
- Независимость ⇔ $f(x,y)=f_X(x)f_Y(y)$. Непрямоугольный носитель ⇒ **зависимы** сразу.
- $\mathrm P((X,Y)\in A)=\iint_A f$. **Отношение площадей — только для равномерной плотности!** (в 35: $\mathrm P(Y>X/2)=\int_0^1\!\int_{x/2}^x 8xy=\tfrac34$, а не $\tfrac12$).

### 3½. Совместное нормальное (двумерный гауссовский вектор)

**Плотность** ($\rho\ne\pm1$):
$$f(x,y)=\frac{1}{2\pi\sigma_X\sigma_Y\sqrt{1-\rho^2}}\exp\!\left\{-\frac{1}{2(1-\rho^2)}\left[\frac{(x-\mu_X)^2}{\sigma_X^2}-2\rho\frac{(x-\mu_X)(y-\mu_Y)}{\sigma_X\sigma_Y}+\frac{(y-\mu_Y)^2}{\sigma_Y^2}\right]\right\}.$$
- Распознать параметры по виду показателя: коэффициенты при $x^2$, $y^2$, $xy$ → $\sigma_X,\sigma_Y,\rho$ (выделить полный квадрат). Константа перед экспонентой — из нормировки, тоже даёт $\sqrt{1-\rho^2}$.
- Типичное «найти $c$» в $c\,e^{-(ax^2+bxy+cy^2)}$: либо подогнать под формулу выше, либо выделить квадрат по $y$ и взять два гауссовых интеграла: $\int e^{-a t^2}dt=\sqrt{\pi/a}$.
- **Матричная форма:** $f=\dfrac{1}{2\pi\sqrt{\det\Sigma}}e^{-\frac12(\mathbf x-\boldsymbol\mu)^T\Sigma^{-1}(\mathbf x-\boldsymbol\mu)}$, $\Sigma=\begin{pmatrix}\sigma_X^2&\rho\sigma_X\sigma_Y\\ \rho\sigma_X\sigma_Y&\sigma_Y^2\end{pmatrix}$. Показатель $-\frac12 Q$ ⇒ матрица квадратичной формы $Q$ — это $\Sigma^{-1}$.

**Свойства**
- Маргиналы: $X\sim N(\mu_X,\sigma_X^2)$, $Y\sim N(\mu_Y,\sigma_Y^2)$ (интегрируя по $y$, выделяй полный квадрат).
- $\rho=0$ ⇔ независимы ⇔ $f=f_Xf_Y$ (нет члена $xy$).
- Условное: $Y\mid X=x\sim N\!\left(\mu_Y+\rho\frac{\sigma_Y}{\sigma_X}(x-\mu_X),\ \sigma_Y^2(1-\rho^2)\right)$ — среднее линейно по $x$, дисперсия от $x$ не зависит.
- $aX+bY\sim N\big(a\mu_X+b\mu_Y,\ a^2\sigma_X^2+b^2\sigma_Y^2+2ab\rho\sigma_X\sigma_Y\big)$ ⇒ вероятности вида $\mathrm P(X>Y)=\mathrm P(X-Y>0)$ сводятся к $\Phi$.
- Подобрать $c$ так, чтобы $X$ и $Y-cX$ были независимы: $\mathrm{Cov}(X,Y-cX)=0\Rightarrow c=\frac{\mathrm{Cov}(X,Y)}{\sigma_X^2}$.

**Стандартный независимый случай** $X,Y\sim N(0,1)$ независимы, $f=\frac1{2\pi}e^{-(x^2+y^2)/2}$:
- Круговая симметрия ⇒ вероятность угловой области = угол$/2\pi$ (напр. $\mathrm P(X>0,Y>0)=\tfrac14$, $\mathrm P(Y>X)=\tfrac12$, $\mathrm P(|Y|<X)=\tfrac14$). Это **не** отношение площадей, а симметрия плотности.
- Полярные координаты ($dx\,dy=r\,dr\,d\varphi$): $\mathrm P(X^2+Y^2<R^2)=1-e^{-R^2/2}$; $X^2+Y^2\sim\mathrm{Exp}(1/2)$.
- Прямоугольник: $\mathrm P(a<X<b,\ c<Y<d)=(\Phi(b)-\Phi(a))(\Phi(d)-\Phi(c))$.

## 4. Преобразование $Y=g(X)$

**Алгоритм**
1. Найти **диапазон $Y$** (образ носителя).
2. Метод функции распределения: $F_Y(y)=\mathrm P(g(X)\le y)$ → выразить через $F_X$ → $f_Y=F_Y'$.
3. Вне диапазона $F_Y=0$ или $1$ — расписать кусочно.

**Монотонная (диффеоморфизм)**
$$f_Y(y)=f_X\big(g^{-1}(y)\big)\,\big|(g^{-1})'(y)\big|.$$
- Подставлять в $f_X$ **сам аргумент** $g^{-1}(y)$; если $f_X$ — константа (равномерное), она и остаётся константой.
- Убывающая $g$: $F_Y(y)=1-F_X(g^{-1}(y))$.

**Немонотонная** — сумма по всем прообразам:
$$f_Y(y)=\sum_{x_i:\,g(x_i)=y} \frac{f_X(x_i)}{|g'(x_i)|}.$$
Пример: $Y=X^2$: $F_Y(y)=F_X(\sqrt y)-F_X(-\sqrt y)$, $f_Y=\frac{f_X(\sqrt y)+f_X(-\sqrt y)}{2\sqrt y}$.
- «Обрезка носителем»: если $-\sqrt y$ вне носителя, $F_X(-\sqrt y)=0$ — берём правильную ветку $F_X$.
- Число прообразов может меняться с $y$ ⇒ $f_Y$ кусочная.

**Частые случаи**
- $Y=aX+b$: $f_Y(y)=\frac1{|a|}f_X\!\left(\frac{y-b}a\right)$.
- $X\sim U[0,1]$, $Y=-\frac1\lambda\ln X\sim\mathrm{Exp}(\lambda)$.
- $Y=F_X(X)\sim U[0,1]$.

## Ловушки (по сделанным ошибкам)
- Нижний предел $F$ — край носителя, не $-\infty$.
- Квадрат в экспоненте нормальной; $\sqrt{2\pi}$, а не $2\pi$.
- Мода — по $f$, не по $F$.
- Не терять множитель $x$ при нормировке ($c$) и $\tfrac12$ при интегрировании.
- Пределы внутреннего интеграла от носителя (в 34: $y\le1-x$).
- $\rho$ — деление на $\sigma_X\sigma_Y$.
- $\mathrm{Var}$ — с квадратом; $\mathrm P(|Y|>a)=1-\mathrm P(|Y|\le a)$.
- $\mathrm P(T\ge t)=1-\Phi$.
- Квантиль — по таблице точно (0.995, а не 0.955), а не «середина диапазона».
