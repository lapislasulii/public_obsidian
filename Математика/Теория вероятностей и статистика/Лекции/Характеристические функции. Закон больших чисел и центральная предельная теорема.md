# Характеристические функции. Закон больших чисел и центральная предельная теорема

## Обзор лекции

Лекция продолжает разговор о характеристических функциях, начатый на предыдущем занятии. Сначала вычисляются характеристические функции стандартных распределений: вырожденного, Бернулли, биномиального, геометрического, отрицательного биномиального, равномерного, нормального, Пуассона, экспоненциального, гамма и Коши. Для нормального и гамма-распределений используется приём «дифференциальное уравнение для $f(t)$ + начальное условие». Затем формулируется теорема о взаимно однозначном соответствии между распределениями и характеристическими функциями и выводятся её следствия: суммы независимых пуассоновских, гауссовских и коши-величин в одну строку, критерий симметричности ($f$ вещественна) и критерий целочисленности ($f$ является $2\pi$-периодической). Для целочисленных величин через ряд Фурье в пространстве $L_2$ выводится формула обращения для вероятностей $p_k$. Далее формулируется теорема Леви о непрерывном соответствии (сходимость по распределению равносильна поточечной сходимости характеристических функций), и с её помощью доказываются два фундаментальных результата: закон больших чисел и центральная предельная теорема для независимых одинаково распределённых величин.

## Предварительные сведения

- **Характеристическая функция** случайной величины $X$: $f_X(t) = \mathbb{E}\, e^{itX}$, $t \in \mathbb{R}$. Для дискретной величины $f_X(t) = \sum_k p_k e^{itx_k}$, для абсолютно непрерывной $f_X(t) = \int_{-\infty}^{+\infty} e^{itx} p(x)\,dx$.
- **Простейшие свойства** (с прошлой лекции): $f_X(0) = 1$; $|f_X(t)| \le 1$; $f_{aX+b}(t) = e^{itb} f_X(at)$; для независимых $X, Y$ выполнено $f_{X+Y}(t) = f_X(t) f_Y(t)$; $\overline{f_X(t)} = f_{-X}(t)$; если распределение симметрично относительно нуля, то $f_X$ принимает вещественные значения.
- **Формула Тейлора в окрестности нуля** (с прошлой лекции): если $\mathbb{E}X^2 < \infty$, то $f_X(t) = 1 + it\,\mathbb{E}X + \dfrac{(it)^2}{2}\,\mathbb{E}X^2 + o(t^2)$ при $t \to 0$; если $\mathbb{E}|X| < \infty$, то $f_X(t) = 1 + it\,\mathbb{E}X + o(t)$.
- **Сходимость по распределению**: $X_n \xrightarrow{d} X$, если $F_{X_n}(x) \to F_X(x)$ в каждой точке непрерывности $F_X$. **Сходимость по вероятности**: $X_n \xrightarrow{P} X$, если $P(|X_n - X| > \varepsilon) \to 0$ для любого $\varepsilon > 0$. Из прошлой лекции: сходимость по распределению к константе влечёт сходимость по вероятности к ней же.
- **Второй замечательный предел**: $\left(1 + \dfrac{a}{n}\right)^n \to e^{a}$ при $n \to \infty$; для комплексного $a$ он тоже верен.
- **Связь распределений через суммы**: биномиальное $\mathrm{Bin}(n,p)$ — сумма $n$ независимых $\mathrm{Bern}(p)$; отрицательное биномиальное с натуральным параметром $r$ — сумма $r$ независимых геометрических; гамма с натуральным $\alpha$ — сумма $\alpha$ независимых экспоненциальных.

## 1. Характеристические функции стандартных распределений

### 1.1. Дискретные распределения

**Пример 1.1 (вырожденное распределение в точке $c$).** Величина $X$ принимает значение $c$ с вероятностью $1$, поэтому
$$f(t) = \mathbb{E}\, e^{itX} = e^{itc}.$$

**Пример 1.2 (Бернулли $\mathrm{Bern}(p)$, $q = 1-p$).**
$$f(t) = p\, e^{it\cdot 1} + q\, e^{it \cdot 0} = p\, e^{it} + q.$$

**Пример 1.3 (биномиальное $\mathrm{Bin}(n,p)$).** Прямое вычисление возможно, но проще вспомнить, что $X = \xi_1 + \dots + \xi_n$ с независимыми $\xi_k \sim \mathrm{Bern}(p)$. Характеристическая функция суммы независимых величин равна произведению характеристических функций, поэтому
$$f(t) = \left(p\, e^{it} + q\right)^n.$$

**Пример 1.4 (геометрическое $\mathrm{Geom}(p)$, $P(X = k) = p q^k$, $k = 0, 1, 2, \dots$).**
$$f(t) = \sum_{k=0}^{\infty} p\, q^k e^{itk} = p \sum_{k=0}^{\infty} \left(q e^{it}\right)^k = \frac{p}{1 - q e^{it}}.$$
Формула суммы геометрической прогрессии верна и для комплексного знаменателя, так как $|q e^{it}| = q < 1$.

**Пример 1.5 (отрицательное биномиальное $\mathrm{NB}(r,p)$, $r \in \mathbb{N}$).** Геометрическая величина считает число неудач до первого успеха, отрицательная биномиальная при натуральном $r$ — число неудач до успеха с номером $r$. Значит, это сумма $r$ независимых одинаково распределённых геометрических величин, и
$$f(t) = \left(\frac{p}{1 - q e^{it}}\right)^r.$$

**Пример 1.6 (Пуассон $\mathrm{Pois}(\lambda)$).**
$$f(t) = \sum_{k=0}^{\infty} e^{itk} e^{-\lambda} \frac{\lambda^k}{k!} = e^{-\lambda} \sum_{k=0}^{\infty} \frac{\left(\lambda e^{it}\right)^k}{k!} = e^{-\lambda}\, e^{\lambda e^{it}} = e^{\lambda\left(e^{it} - 1\right)}.$$

МОТИВАЦИЯ: Для дискретных распределений характеристическая функция вычисляется как сумма ряда, а для распределений, связанных суммированием, формула получается из свойства «произведение для суммы независимых» без новых вычислений.

ИНТУИЦИЯ: Чем «сложнее» распределение как свёртка простых, тем проще его характеристическая функция как степень или произведение простых.

### 1.2. Непрерывные распределения

**Пример 1.7 (равномерное $U[a,b]$).**
$$f(t) = \frac{1}{b-a} \int_a^b e^{itx}\,dx = \frac{e^{itb} - e^{ita}}{it\,(b-a)}.$$

*Частный случай $a = -b$* (распределение симметрично относительно нуля):
$$f(t) = \frac{e^{itb} - e^{-itb}}{2itb} = \frac{\left(\cos tb + i \sin tb\right) - \left(\cos tb - i \sin tb\right)}{2itb} = \frac{2i \sin tb}{2itb} = \frac{\sin tb}{tb}.$$
Косинусы взаимно уничтожаются, а мнимая единица и двойка сокращаются. Результат вещественный, что согласуется со свойством: для симметричного распределения характеристическая функция вещественнозначна.

**Пример 1.8 (стандартное нормальное $N(0,1)$).** По определению
$$f(t) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{+\infty} e^{itx - x^2/2}\,dx.$$
Напрямую такой интеграл взять трудно, поэтому используется приём: получить для $f$ дифференциальное уравнение.

Идея: продифференцировать по $t$ (производную можно вносить под знак интеграла), проинтегрировать по частям и выразить результат через саму $f$.

Шаг 1. Дифференцируем под знаком интеграла:
$$f'(t) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{+\infty} ix\, e^{itx}\, e^{-x^2/2}\,dx.$$
Шаг 2. Замечаем, что $x\, e^{-x^2/2} = -\left(e^{-x^2/2}\right)'$. Интегрируем по частям, интегрируя $x e^{-x^2/2}$ и дифференцируя $e^{itx}$:
$$f'(t) = \frac{-i}{\sqrt{2\pi}} \left. e^{itx} e^{-x^2/2} \right|_{-\infty}^{+\infty} + \frac{i}{\sqrt{2\pi}} \int_{-\infty}^{+\infty} it\, e^{itx}\, e^{-x^2/2}\,dx.$$
Шаг 3. Двойная подстановка равна нулю: $|e^{itx}| = 1$ (ограниченный множитель), а $e^{-x^2/2} \to 0$ при $x \to \pm\infty$. Остаётся
$$f'(t) = i^2 t \cdot \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{+\infty} e^{itx - x^2/2}\,dx = -t\, f(t).$$
Шаг 4. Итак, $f'(t) = -t\, f(t)$, $f(0) = 1$. Функция $f(t) = e^{-t^2/2}$ удовлетворяет и уравнению (левая и правая части равны $-t e^{-t^2/2}$), и начальному условию. Решение задачи Коши в данной ситуации единственно, поэтому
$$f_{N(0,1)}(t) = e^{-t^2/2}. \qquad \square$$

> [!NOTE] Дополнено
> Как решать такие уравнения напрямую (метод разделения переменных, лектор обещал подробнее в следующем семестре). Запишем $f' = \dfrac{df}{dt}$, тогда $\dfrac{df}{f} = -t\,dt$. Интегрируем обе части: $\ln |f| = -\dfrac{t^2}{2} + C$, то есть $f(t) = C_1 e^{-t^2/2}$. Константа однозначно определяется условием $f(0) = 1$, откуда $C_1 = 1$.

**Пример 1.9 (произвольное нормальное $N(\mu, \sigma^2)$).** Произвольная гауссовская величина выражается через стандартную: $Y = \sigma X + \mu$, где $X \sim N(0,1)$ (обратная операция к стандартизации). По свойству $f_{aX+b}(t) = e^{itb} f_X(at)$:
$$f_Y(t) = e^{it\mu}\, f_X(\sigma t) = e^{it\mu - \sigma^2 t^2/2}.$$

**Пример 1.10 (экспоненциальное $\mathrm{Exp}(\lambda)$, плотность $\lambda e^{-\lambda x}$, $x \ge 0$).**
$$f(t) = \int_0^{\infty} \lambda\, e^{itx - \lambda x}\,dx = \lambda \left. \frac{e^{(it - \lambda)x}}{it - \lambda} \right|_0^{\infty} = \frac{\lambda}{\lambda - it}.$$
На бесконечности $|e^{(it-\lambda)x}| = e^{-\lambda x} \to 0$, в нуле значение равно $1$.

**Пример 1.11 (гамма-распределение $\Gamma(\alpha, \lambda)$, плотность $\dfrac{\lambda^\alpha x^{\alpha-1} e^{-\lambda x}}{\Gamma(\alpha)}$, $x > 0$).**

Утверждение. $f(t) = \left(\dfrac{\lambda}{\lambda - it}\right)^{\alpha}$.

Доказательство. Идея: тот же приём, что для нормального закона.

Шаг 1. Дифференцируем под знаком интеграла:
$$f'(t) = i \int_0^{\infty} \frac{\lambda^\alpha\, x^{\alpha}\, e^{-\lambda x}}{\Gamma(\alpha)}\, e^{itx}\,dx.$$
Шаг 2. Интегрируем по частям: $u = x^{\alpha}$, $dv = e^{(it - \lambda)x}\,dx$, $v = \dfrac{e^{(it-\lambda)x}}{it - \lambda}$ (именно множитель $e^{-\lambda x} e^{itx} = e^{(it-\lambda)x}$ нужно интегрировать целиком). Внеинтегральный член равен нулю: на бесконечности экспонента убивает степень, в нуле обнуляет $x^\alpha$. Получаем
$$f'(t) = -\frac{i\alpha}{it - \lambda} \int_0^{\infty} \frac{\lambda^\alpha\, x^{\alpha-1}\, e^{-\lambda x}}{\Gamma(\alpha)}\, e^{itx}\,dx = \frac{i\alpha}{\lambda - it}\, f(t).$$
Шаг 3. Решаем $\dfrac{f'}{f} = \dfrac{i\alpha}{\lambda - it}$ с условием $f(0) = 1$: $\ln f = -\alpha \ln (\lambda - it) + C$, откуда $f(t) = \left(\dfrac{\lambda}{\lambda - it}\right)^\alpha$. Проверка: $\left(\dfrac{\lambda^\alpha}{(\lambda - it)^\alpha}\right)' = \lambda^\alpha \cdot (-\alpha)(\lambda - it)^{-\alpha-1}\cdot(-i) = \dfrac{i\alpha}{\lambda - it}\, f(t)$. $\square$

> [!NOTE] Дополнено
> На лекции при первой попытке интегрирования по частям была допущена ошибка (интегрировали только $e^{-\lambda x}$ без множителя $e^{itx}$), и уравнение не сходилось; после замечания из аудитории выкладка была исправлена. Выше приведён исправленный вариант.

Замечание 1.1. Для натурального $\alpha$ ответ получается и без вычислений: гамма-величина с натуральным $\alpha$ есть сумма $\alpha$ независимых экспоненциальных, а характеристическая функция экспоненциального закона возводится в степень $\alpha$.

**Пример 1.12 (распределение Коши с параметрами $\mu$ и $\gamma$).** Приводится без вывода (вывод требует комплексного анализа, вычетов):
$$f(t) = e^{it\mu - \gamma |t|}.$$

МОТИВАЦИЯ: Непосредственное вычисление интегралов $\int e^{itx} p(x)\,dx$ часто тяжело, а характеристические функции нужны как инструмент для остальной лекции.

ИНТУИЦИЯ: Характеристическая функция нормального закона с точностью до масштаба снова гауссиана: нормальный закон «самодуален» относительно преобразования Фурье. У распределения Коши $f$ имеет «угол» в нуле ($|t|$), что отражает отсутствие у него математического ожидания.

## 2. Теорема единственности и её следствия

### 2.1. Взаимно однозначное соответствие

Теорема 2.1 (единственности, без доказательства). Соответствие между распределениями и характеристическими функциями взаимно однозначно: по характеристической функции можно однозначно восстановить распределение. В частности, если $f_X \equiv f_Y$, то $X \overset{d}{=} Y$.

МОТИВАЦИЯ: Иногда задачу тяжело решать в исходном пространстве (распределений, плотностей, свёрток). Тогда переходят в другое пространство, где она решается проще, а потом возвращаются назад. Характеристическая функция — вероятностная интерпретация преобразования Фурье, и теорема единственности гарантирует, что возвращаться назад можно без потерь.

ИНТУИЦИЯ: Характеристическая функция — «отпечаток» распределения: два разных распределения не могут иметь один и тот же отпечаток. При этом свёртка (сложная операция) превращается в обычное умножение (простая операция).

### 2.2. Суммы независимых величин

**Пример 2.1 (сумма пуассоновских).** Пусть $X_1 \sim \mathrm{Pois}(\lambda_1)$, $X_2 \sim \mathrm{Pois}(\lambda_2)$ независимы. Тогда
$$f_{X_1 + X_2}(t) = e^{\lambda_1 (e^{it} - 1)}\, e^{\lambda_2 (e^{it} - 1)} = e^{(\lambda_1 + \lambda_2)(e^{it} - 1)}.$$
Это характеристическая функция $\mathrm{Pois}(\lambda_1 + \lambda_2)$, поэтому по теореме единственности $X_1 + X_2 \sim \mathrm{Pois}(\lambda_1 + \lambda_2)$.

**Пример 2.2 (сумма гауссовских).** Пусть $X_k \sim N(\mu_k, \sigma_k^2)$ независимы, $k = 1, 2$. Тогда
$$f_{X_1+X_2}(t) = e^{it\mu_1 - \sigma_1^2 t^2/2}\, e^{it\mu_2 - \sigma_2^2 t^2/2} = e^{it(\mu_1 + \mu_2) - (\sigma_1^2 + \sigma_2^2)t^2/2},$$
то есть $X_1 + X_2 \sim N(\mu_1 + \mu_2,\ \sigma_1^2 + \sigma_2^2)$: математические ожидания и дисперсии складываются.

**Пример 2.3 (сумма величин Коши).** Сумма независимых величин Коши снова имеет распределение Коши, параметры складываются (при общем виде $e^{it\mu - \gamma|t|}$ складываются $\mu$ и $\gamma$).

Замечание 2.1. Через свёртку каждое из этих утверждений доказывается значительно тяжелее: для Коши интеграл свёртки неприятный (лектор отметил, что быстро посчитать его не удалось), для нормального закона путь «через свёртку» — «путь самурая». Через характеристические функции доказательство занимает одну строку.

### 2.3. Критерий симметричности

Теорема 2.2. Распределение случайной величины $X$ симметрично относительно нуля ($X \overset{d}{=} -X$) тогда и только тогда, когда $f_X$ принимает только вещественные значения.

Доказательство. Идея: связать комплексное сопряжение с заменой $X \mapsto -X$ и применить теорему единственности.

(a) Необходимость (с прошлой лекции): если $X \overset{d}{=} -X$, то $f_X(t) = f_{-X}(t) = \overline{f_X(t)}$, значит $f_X$ вещественна.
(b) Достаточность. Пусть $f_X$ вещественна, то есть $f_X = \overline{f_X}$. Но $\overline{f_X(t)} = \mathbb{E}\, e^{-itX} = f_{-X}(t)$. Следовательно $f_X = f_{-X}$, и по теореме единственности $X \overset{d}{=} -X$. $\square$

МОТИВАЦИЯ: Симметричность проверяется по виду характеристической функции без обращения к плотности.

ИНТУИЦИЯ: Мнимая часть $f_X(t) = \mathbb{E}\sin tX$ — это «несимметричная часть» распределения; она обнуляется ровно тогда, когда $X$ и $-X$ распределены одинаково.

### 2.4. Критерий целочисленности

Теорема 2.3. Случайная величина $X$ принимает только целые значения (целочисленна) тогда и только тогда, когда $f_X$ является $2\pi$-периодической.

Доказательство. Идея: периодичность означает $f_X(2\pi) = f_X(0) = 1$, а равенство единице модуля среднего значения $e^{i\cdot 2\pi X}$ возможно только когда $e^{2\pi i X} = 1$ почти наверное.

(a) Необходимость. Пусть $P(X = k) = p_k$, $k \in \mathbb{Z}$. Тогда
$$f_X(t) = \sum_{k \in \mathbb{Z}} p_k\, e^{itk} = \sum_{k} p_k \left(\cos tk + i \sin tk\right).$$
Каждое слагаемое $e^{itk}$ с целым $k$ имеет период $2\pi$, значит и сумма $2\pi$-периодична.

(b) Достаточность. Пусть $f_X$ $2\pi$-периодична. Тогда $f_X(2\pi) = f_X(0) = 1$. С другой стороны,
$$f_X(2\pi) = \mathbb{E}\cos 2\pi X + i\, \mathbb{E}\sin 2\pi X.$$
Два комплексных числа равны тогда и только тогда, когда равны их вещественные и мнимые части. Отсюда $\mathbb{E}\sin 2\pi X = 0$ и $\mathbb{E}\cos 2\pi X = 1$, то есть
$$\mathbb{E}\left(1 - \cos 2\pi X\right) = 0.$$
При этом $1 - \cos 2\pi X \in [0, 2]$, то есть случайная величина $1 - \cos 2\pi X$ неотрицательна. Неотрицательная случайная величина с нулевым математическим ожиданием равна нулю почти наверное. Поэтому $\cos 2\pi X = 1$ с вероятностью $1$, то есть $2\pi X = 2\pi k$ для некоторого целого $k$, и $X = k \in \mathbb{Z}$ с вероятностью $1$. $\square$

МОТИВАЦИЯ: Для целочисленных величин (а значит, для всех дискретных распределений на $\mathbb{Z}$) из периодичности можно изучать $f$ не на всей прямой, а на отрезке длины периода, например $[-\pi, \pi]$. Это приводит к ряду Фурье и явной формуле обращения.

ИНТУИЦИЯ: Для целочисленной величины $f_X$ — тригонометрический ряд с коэффициентами $p_k$; такой ряд обязан быть периодичным, и верно обратное.

## 3. Формула обращения для целочисленных величин

Рассмотрим пространство комплекснозначных функций на отрезке $[-\pi, \pi]$:
$$L_2 = \left\{ f : [-\pi, \pi] \to \mathbb{C} \;\middle|\; \int_{-\pi}^{\pi} f(t)\, \overline{f(t)}\,dt = \int_{-\pi}^{\pi} |f(t)|^2\,dt < \infty \right\}.$$

Определение 3.1. Для $f, g \in L_2$ положим
$$\langle f, g \rangle = \int_{-\pi}^{\pi} f(t)\, \overline{g(t)}\,dt.$$

Свойства (проверяются по определению интеграла):
- $\langle g, f \rangle = \overline{\langle f, g \rangle}$ (эрмитова симметрия: перестановка аргументов даёт комплексное сопряжение);
- $\langle \alpha f + \beta h,\ g \rangle = \alpha \langle f, g \rangle + \beta \langle h, g \rangle$ (линейность по первому аргументу);
- $\langle f, f \rangle = \int |f|^2\,dt \ge 0$, причём $\langle f, f \rangle = 0$ только при $f = 0$ (почти всюду).

Это аксиомы скалярного произведения в комплексном пространстве. Оно порождает норму $\|f\| = \sqrt{\langle f, f \rangle} = \sqrt{\int_{-\pi}^{\pi} |f(t)|^2 dt}$ (отсюда название $L_2$: норма — «$2$-норма» для функций, аналог $\sqrt{\sum x_i^2}$ для векторов), расстояние $\rho(f,g) = \|f - g\|$ и сходимость: $f_n \to f$, если $\|f - f_n\| \to 0$.

МОТИВАЦИЯ: Хотим разложить $2\pi$-периодическую функцию по «простейшим» периодическим функциям и вычислять коэффициенты разложения скалярным произведением, как координаты вектора в ортогональном базисе.

ИНТУИЦИЯ: Функции на отрезке ведут себя как векторы бесконечной размерности; скалярное произведение — аналог $\sum x_i \bar y_i$.

Теорема 3.1 (ортогональность экспонент). Для целых $k, j$
$$\langle e^{itk}, e^{itj} \rangle = \int_{-\pi}^{\pi} e^{it(k - j)}\,dt = \begin{cases} 2\pi, & k = j, \\ 0, & k \ne j. \end{cases}$$

Доказательство. Если $k = j$, подынтегральная функция равна $1$, интеграл равен $2\pi$. Если $k \ne j$, то
$$\int_{-\pi}^{\pi} e^{it(k-j)}\,dt = \left. \frac{e^{it(k-j)}}{i(k-j)} \right|_{-\pi}^{\pi} = \frac{e^{i\pi(k-j)} - e^{-i\pi(k-j)}}{i(k-j)} = \frac{2i \sin \pi(k-j)}{i(k-j)} = 0,$$
так как $\sin \pi m = 0$ при целом $m$. $\square$

Утверждение 3.1 (неформально, без доказательства полноты). Семейство $\{e^{itk}\}_{k \in \mathbb{Z}}$ является базисом в $L_2$: любую $f \in L_2$ можно записать как
$$f(t) = \sum_{k \in \mathbb{Z}} c_k\, e^{itk},$$
где равенство понимается в смысле $L_2$, то есть частичные суммы сходятся к $f$ по норме $\|\cdot\|$.

Коэффициенты. Скалярно умножим обе части на $e^{itj}$. По ортогональности все слагаемые, кроме $k = j$, обнуляются:
$$\langle f, e^{itj} \rangle = c_j \cdot 2\pi, \qquad c_j = \frac{1}{2\pi} \int_{-\pi}^{\pi} f(t)\, e^{-itj}\,dt.$$
(Сопряжение экспоненты меняет знак в показателе.)

Следствие 3.1 (формула обращения для целочисленных величин). Если $X$ целочисленна, то $f_X(t) = \sum_k p_k e^{itk}$ — уже готовое разложение по этому базису, поэтому $c_k = p_k$ и
$$p_k = P(X = k) = \frac{1}{2\pi} \int_{-\pi}^{\pi} f_X(t)\, e^{-itk}\,dt.$$

> [!WARNING] Восстановлено
> В записи формула обращения проговорена как «один по пи» (нечётко), а коэффициент в явном виде в тексте не разобран. Здесь использован множитель $\dfrac{1}{2\pi}$, который следует из вывода $c_j$ выше (ортогональность даёт $2\pi$ в знаменателе). Стоит перепроверить по учебнику.

МОТИВАЦИЯ: Явно показать, что по характеристической функции вероятности восстанавливаются не только теоретически (теорема единственности), но и по конкретной формуле.

ИНТУИЦИЯ: Умножение на $e^{-itk}$ и интегрирование «вырезает» из ряда ровно $k$-ю гармонику, как фильтр, настроенный на частоту $k$.

Замечание 3.1. Формула обращения существует и для общего случая (непрерывные распределения), но носит скорее теоретический характер и в практических приложениях неудобна; для целочисленных величин она вполне приятна.

## 4. Теорема Леви о непрерывном соответствии

Теорема 4.1 (Леви, без доказательства). Пусть $X_n$ и $X$ — случайные величины с характеристическими функциями $f_n$ и $f$. Тогда
$$X_n \xrightarrow{d} X \iff f_n(t) \to f(t) \ \text{ при } n \to \infty \ \text{ для каждого } t \in \mathbb{R}.$$

То есть сходимость по распределению равносильна поточечной сходимости характеристических функций.

> [!NOTE] Дополнено
> В более общей версии теоремы Леви достаточно, чтобы $f_n(t)$ сходились поточечно к функции, непрерывной в нуле; тогда эта функция автоматически является характеристической функцией некоторой величины. Для доказательств ниже достаточно приведённой формулировки.

МОТИВАЦИЯ: Сходимость по распределению в терминах функций распределения проверять тяжело. Теорема Леви превращает её в проверку обычной поточечной сходимости функций, к которой применимы пределы и формула Тейлора.

ИНТУИЦИЯ: Поскольку отпечаток однозначно определяет распределение и устойчив относительно пределов, «близкие отпечатки» означают «близкие распределения».

СВЯЗИ: Теорема Леви — главный инструмент двух доказательств далее.

## 5. Закон больших чисел

Теорема 5.1 (закон больших чисел, ЗБЧ). Пусть $X_1, X_2, \dots$ — независимые одинаково распределённые случайные величины с $\mathbb{E}X_k = \mu$ (конечным). Тогда
$$\frac{1}{n} \sum_{k=1}^{n} X_k \xrightarrow{P} \mu \quad (n \to \infty),$$
то есть усреднённая сумма сходится по вероятности к математическому ожиданию (вырожденной величине в точке $\mu$).

Доказательство. Идея: показать сходимость характеристических функций к $e^{it\mu}$ (характеристической функции вырожденного закона в точке $\mu$), применить теорему Леви и перейти от сходимости по распределению к сходимости по вероятности.

Шаг 1. По формуле Тейлора в окрестности нуля (достаточно $\mathbb{E}|X_1| < \infty$)
$$f_{X_1}(t) = 1 + it\mu + o(t), \quad t \to 0.$$
Шаг 2. Величины независимы и одинаково распределены, поэтому
$$f_{X_1 + \dots + X_n}(t) = \left(f_{X_1}(t)\right)^n = \left(1 + it\mu + o(t)\right)^n.$$
Шаг 3. Для среднего используем $f_{aY}(t) = f_Y(at)$ при $a = \frac1n$:
$$f_{\frac1n \sum X_k}(t) = \left(f_{X_1}\!\left(\frac{t}{n}\right)\right)^n = \left(1 + \frac{it\mu}{n} + o\!\left(\frac1n\right)\right)^n.$$
Шаг 4. Фиксируем $t$ и переходим к пределу по $n$. Здесь $t/n \to 0$, поэтому разложение Тейлора применимо. По второму замечательному пределу (знак в показателе $+it\mu$, без минуса)
$$\left(1 + \frac{it\mu}{n} + o\!\left(\frac1n\right)\right)^n \to e^{it\mu}.$$
Шаг 5. Функция $e^{it\mu}$ — характеристическая функция вырожденного закона в точке $\mu$ (Пример 1.1). По теореме Леви $\frac1n \sum X_k \xrightarrow{d} \mu$.
Шаг 6. Сходимость по распределению к константе влечёт сходимость по вероятности (доказано на прошлой лекции), поэтому $\frac1n \sum X_k \xrightarrow{P} \mu$. $\square$

> [!NOTE] Дополнено
> Обоснование предела в шаге 4 для комплексных чисел. Пусть $z_n \to z \in \mathbb{C}$. При $|w| < 1/2$ главная ветвь логарифма удовлетворяет $\ln(1 + w) = w + O(|w|^2)$. Тогда $n \ln\left(1 + \dfrac{z_n}{n}\right) = z_n + O\!\left(\dfrac1n\right) \to z$, откуда $\left(1 + \dfrac{z_n}{n}\right)^n \to e^{z}$. Здесь $z_n = it\mu + n\, o(1/n) \to it\mu$.

МОТИВАЦИЯ: Строго обосновать интуитивный факт: среднее арифметическое большого числа независимых наблюдений стабилизируется около математического ожидания.

ИНТУИЦИЯ: Случайные отклонения в разные стороны взаимно гасятся при усреднении, а множитель $\frac1n$ сжимает остаточный разброс до нуля.

ТИПИЧНЫЕ ОШИБКИ: (1) Путать знак в показателе: предел равен $e^{it\mu}$, а не $e^{-it\mu}$. (2) Забывать, что теорема Леви даёт сходимость по распределению, а в формулировке ЗБЧ написана сходимость по вероятности; переход обеспечивается тем, что предел — константа.

## 6. Центральная предельная теорема

Теорема 6.1 (ЦПТ для независимых одинаково распределённых величин). Пусть $X_1, X_2, \dots$ независимы, одинаково распределены, $\mathbb{E}X_k = \mu$, $\mathbb{D}X_k = \sigma^2 \in (0, \infty)$. Тогда
$$\frac{\sum_{k=1}^{n} X_k - n\mu}{\sqrt{n\sigma^2}} \xrightarrow{d} U, \qquad U \sim N(0,1).$$

Случай $\sigma^2 = 0$ неинтересен: тогда величина вырождена.

Доказательство. Идея: центрировать и нормировать слагаемые, разложить характеристическую функцию по Тейлору до второго порядка и воспользоваться вторым замечательным пределом.

Шаг 1. Перепишем левую часть:
$$\frac{\sum X_k - n\mu}{\sqrt{n\sigma^2}} = \frac{1}{\sqrt n} \sum_{k=1}^{n} \frac{X_k - \mu}{\sigma} = \frac{1}{\sqrt n} \sum_{k=1}^{n} Y_k, \qquad Y_k = \frac{X_k - \mu}{\sigma}.$$
Шаг 2. Величины $Y_k$ независимы, одинаково распределены, $\mathbb{E}Y_k = 0$, $\mathbb{D}Y_k = 1$, а значит $\mathbb{E}Y_k^2 = 1$.
Шаг 3. По формуле Тейлора
$$f_{Y_1}(t) = 1 + it \cdot 0 + \frac{(it)^2}{2} \cdot 1 + o(t^2) = 1 - \frac{t^2}{2} + o(t^2).$$
Шаг 4. Характеристическая функция суммы $\sum Y_k$: $\left(f_{Y_1}(t)\right)^n$. Характеристическая функция $\frac{1}{\sqrt n}\sum Y_k$ получается подстановкой аргумента $\frac{t}{\sqrt n}$:
$$f_{\frac{1}{\sqrt n} \sum Y_k}(t) = \left(f_{Y_1}\!\left(\frac{t}{\sqrt n}\right)\right)^n = \left(1 - \frac{t^2}{2n} + o\!\left(\frac1n\right)\right)^n.$$
Шаг 5. Переходим к пределу (второй замечательный предел):
$$\left(1 - \frac{t^2}{2n} + o\!\left(\frac1n\right)\right)^n \to e^{-t^2/2}, \quad n \to \infty.$$
Шаг 6. Это характеристическая функция $N(0,1)$ (Пример 1.8). По теореме Леви сходимость характеристических функций влечёт сходимость по распределению к стандартному нормальному закону. $\square$

МОТИВАЦИЯ: ЦПТ объясняет универсальную роль нормального распределения: сумма большого числа независимых малых вкладов почти нормальна, какими бы ни были распределения слагаемых (лишь бы выполнялись условия на моменты).

ИНТУИЦИЯ: Центрирование убирает сдвиг $n\mu$, нормировка на $\sqrt{n\sigma^2}$ компенсирует рост разброса суммы (дисперсия суммы равна $n\sigma^2$). Слагаемое $-\frac{t^2}{2}$ в разложении — вклад дисперсии, а все остальные детали распределения («хвосты» разложения) при $n \to \infty$ исчезают.

ТИПИЧНЫЕ ОШИБКИ: Аргумент характеристической функции слагаемого следует брать равным $\dfrac{t}{\sqrt n}$ (а не $t$): именно поэтому в разложении остаётся $\dfrac{t^2}{2n}$. В ЗБЧ же аргумент $\dfrac{t}{n}$.

Следствие 6.1 (практический смысл ЦПТ). При больших $n$
$$P\!\left(a \le \frac{\sum_{k=1}^n X_k - n\mu}{\sqrt{n\sigma^2}} \le b\right) \approx \Phi(b) - \Phi(a),$$
где $\Phi$ — функция распределения стандартного нормального закона.

Замечание 6.1. С помощью характеристических функций можно не только доказывать сходимость, но и оценивать её скорость (например, скорость в теореме Пуассона и в ЦПТ). Это технически сложнее, но по сути опирается на те же характеристические функции. В следующей лекции будут приложения ЗБЧ и ЦПТ, после чего начнётся переход к математической статистике, большая часть утверждений которой опирается на ЗБЧ, ЦПТ и свойства сходимостей.

## Справочный лист

Характеристические функции:

| Распределение | $f(t)$ |
|---|---|
| Вырожденное в точке $c$ | $e^{itc}$ |
| $\mathrm{Bern}(p)$ | $p e^{it} + q$ |
| $\mathrm{Bin}(n,p)$ | $(p e^{it} + q)^n$ |
| $\mathrm{Geom}(p)$ ($P(X=k) = pq^k$) | $\dfrac{p}{1 - q e^{it}}$ |
| $\mathrm{NB}(r,p)$ | $\left(\dfrac{p}{1 - q e^{it}}\right)^r$ |
| $\mathrm{Pois}(\lambda)$ | $e^{\lambda(e^{it} - 1)}$ |
| $U[a,b]$ | $\dfrac{e^{itb} - e^{ita}}{it(b-a)}$ |
| $U[-b,b]$ | $\dfrac{\sin tb}{tb}$ |
| $N(0,1)$ | $e^{-t^2/2}$ |
| $N(\mu, \sigma^2)$ | $e^{it\mu - \sigma^2 t^2/2}$ |
| $\mathrm{Exp}(\lambda)$ | $\dfrac{\lambda}{\lambda - it}$ |
| $\Gamma(\alpha, \lambda)$ | $\left(\dfrac{\lambda}{\lambda - it}\right)^\alpha$ |
| Коши $(\mu, \gamma)$ | $e^{it\mu - \gamma|t|}$ |

Основные результаты:
- Теорема единственности: $f_X \equiv f_Y \Rightarrow X \overset{d}{=} Y$.
- $f_X$ вещественна $\iff$ $X \overset{d}{=} -X$.
- $X$ целочисленна $\iff$ $f_X$ $2\pi$-периодична; тогда $p_k = \dfrac{1}{2\pi}\displaystyle\int_{-\pi}^{\pi} f_X(t)\, e^{-itk}\,dt$.
- Ортогональность: $\displaystyle\int_{-\pi}^{\pi} e^{it(k-j)}\,dt = 2\pi\,\delta_{kj}$.
- Теорема Леви: $X_n \xrightarrow{d} X \iff f_n(t) \to f(t)$ для всех $t$.
- ЗБЧ: $\dfrac1n \sum X_k \xrightarrow{P} \mu$.
- ЦПТ: $\dfrac{\sum X_k - n\mu}{\sqrt{n\sigma^2}} \xrightarrow{d} N(0,1)$.

## Концептуальное резюме

Характеристическая функция — преобразование Фурье распределения: она однозначно кодирует распределение и превращает трудную операцию (свёртку при суммировании независимых величин) в простую (умножение). Это позволяет в одну строку доказывать устойчивость пуассоновского, нормального и коши-законов относительно суммирования, а также отслеживать структурные свойства распределения: симметричность соответствует вещественности $f$, целочисленность соответствует $2\pi$-периодичности (с явной формулой обращения через ряд Фурье). Главный инструмент лекции — теорема Леви: сходимость по распределению эквивалентна поточечной сходимости характеристических функций. Вместе с формулой Тейлора $f(t) = 1 + it\mu - \frac{t^2}{2}\mathbb{E}X^2 + \dots$ и вторым замечательным пределом она даёт короткие доказательства закона больших чисел (предел $e^{it\mu}$, вырожденный закон) и центральной предельной теоремы (предел $e^{-t^2/2}$, нормальный закон).

## Связи с более широкой математикой

- Преобразование Фурье и ряды Фурье в $L_2$: характеристическая функция — это преобразование Фурье меры; формула обращения для целочисленных величин — коэффициенты ряда Фурье.
- Гильбертовы пространства: $L_2$ со скалярным произведением, ортогональные базисы, сходимость по норме.
- Дифференциальные уравнения: приём «получить ОДУ для $f$ и решить задачу Коши» (метод разделения переменных); единственность решения задачи Коши.
- Комплексный анализ: вывод характеристической функции распределения Коши вычетами.
- Математическая статистика (следующие лекции): ЗБЧ и ЦПТ лежат в основе состоятельности оценок, построения доверительных интервалов и асимптотических тестов.
- Скорость сходимости в ЦПТ и теореме Пуассона: оценки через характеристические функции.
