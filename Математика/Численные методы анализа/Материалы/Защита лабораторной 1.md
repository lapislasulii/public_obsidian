## 2. Теоретические сведения

### 2.1 Линейная регрессия

Модель линейной регрессии задаёт зависимость целевой переменной $y$ от признаков $X$:

$$y = Xw + \varepsilon$$

где:
- $X \in \mathbb{R}^{n \times d}$ — матрица признаков ($n$ объектов, $d$ признаков),
- $w \in \mathbb{R}^d$ — вектор весов (коэффициентов),
- $y \in \mathbb{R}^n$ — вектор целевых значений,
- $\varepsilon$ — вектор случайных ошибок.

**Задача обучения** — найти веса $w^*$, минимизирующие сумму квадратов остатков (МНК):

$$w^* = \arg\min_w \|Xw - y\|^2$$

### 2.2 Метод наименьших квадратов и нормальное уравнение

Функция потерь МНК:

$$L(w) = \|Xw - y\|^2 = (Xw - y)^T(Xw - y)$$

Берём градиент и приравниваем к нулю:

$$\frac{\partial L}{\partial w} = 2X^T(Xw - y) = 0$$

$$X^T X w = X^T y$$

Это **нормальное уравнение**. При невырожденной матрице $X^T X$:

$$w^* = (X^T X)^{-1} X^T y$$

На практике вместо явного обращения матрицы решают СЛАУ:

$$X^T X \, w = X^T y$$

методом `np.linalg.solve`, что численно устойчивее.

> **Важно для защиты:** свободный член (intercept) вводится добавлением столбца единиц к матрице $X$ перед решением. В коде: `X = np.c_[np.ones(len(X)), X]`. Это расширяет задачу до $(d+1)$ параметра.

### 2.3 Связь с СЛАУ

Нормальное уравнение $X^T X w = X^T y$ — это СЛАУ размера $(d+1) \times (d+1)$. Качество её решения определяется **числом обусловленности** матрицы $A = X^T X$.

## 3. Методы предобработки

### 3.1 StandardScaler (центрирование и нормировка)

**Центрирование** (`with_mean=True`):

$$X' = X - \bar{X}, \quad \bar{X} = \frac{1}{n}\sum_{i=1}^n x_i$$

**Нормировка** (`with_std=True`):

$$X'' = \frac{X'}{\sigma_X}, \quad \sigma_X = \text{std}(X_\text{train})$$

**Полная стандартизация** (`with_mean=True, with_std=True`):

$$X_\text{scaled} = \frac{X - \bar{X}}{\sigma_X}$$

> **Ключевой факт:** параметры масштабирования $\bar{X}$ и $\sigma_X$ вычисляются **только по обучающей выборке** и применяются к тестовой. Это предотвращает утечку информации (data leakage).

**Почему масштабирование не меняет MAE при degree=1?**

Линейная регрессия со свободным членом **инвариантна** к линейному преобразованию признаков. Если $X' = aX + b$, то существуют такие $w'$, что $X'w' = Xw$. Предсказания и MAE остаются теми же.

**Почему масштабирование снижает число обусловленности?**

Без нормировки признаки имеют разные масштабы (например, криминальность от 0 до 90, доля жилых зон от 0 до 100 — а расстояние от 1 до 12). Матрица $X^T X$ при этом плохо обусловлена из-за разброса собственных значений. Деление на $\sigma$ выравнивает масштабы → диапазон собственных значений сужается → $\kappa$ уменьшается.

### 3.2 PolynomialFeatures

Генерирует новые признаки — степени и попарные произведения исходных.

При $d$ исходных признаках и степени $p$ число новых признаков:

$$D = \binom{d + p}{p}$$

Для $d = 13$ (Boston Housing):
- $p = 1$: $D = 13$
- $p = 2$: $D = \binom{15}{2} = 105$ (без исходных: 91 новый, итого с исходными 104)
- $p = 3$: $D = \binom{16}{3} = 560$ → с intercept: **560 признаков** vs **~395 строк обучающей выборки**

> **Важно:** при $p=3$ число признаков ($\approx 559$) превышает число объектов ($\approx 395$). Система **недоопределена**: матрица $X^T X$ вырождена или почти вырождена, МНК-решение точно воспроизводит обучение, но не обобщается.

## 4. Метрики качества

### 4.1 MAE (средняя абсолютная ошибка)

$$\text{MAE} = \frac{1}{n}\sum_{i=1}^n |y_i - \hat{y}_i|$$

Интерпретация: средняя ошибка предсказания в единицах целевой переменной (тыс. долларов для Boston Housing).

### 4.2 Число обусловленности

$$\kappa(A) = \|A\| \cdot \|A^{-1}\| = \frac{\sigma_{\max}}{\sigma_{\min}}$$

где $\sigma_{\max}$, $\sigma_{\min}$ — максимальное и минимальное сингулярные числа матрицы $A = X^T X$.

**Смысл:** если $\kappa(A) \sim 10^k$, то решение СЛАУ теряет порядка $k$ значащих цифр из-за ошибок округления в данных.

В коде число обусловленности считается от **расширенной матрицы** (с добавленным столбцом единиц), так как именно она решается в `fit`:

```python
Xm = np.c_[np.ones(len(X_train_poly)), X_train_poly]
cond = np.linalg.cond(Xm.T @ Xm)
```

### fit и predict (с intercept)
```python
def fit(X, y):
    X = np.c_[np.ones(len(X)), X]       # добавляем столбец единиц
    return np.linalg.solve(X.T @ X, X.T @ y)

def predict(X, w):
    X = np.c_[np.ones(len(X)), X]
    return X @ w
```

> Ключевой момент: `np.c_[np.ones(len(X)), X]` добавляется **внутри** `fit` и `predict`, поэтому передаются признаки **без** столбца единиц.

### Масштабирование
```python
def scale(X_train, X_test, with_mean=False, with_std=False):
    if with_mean:
        mean = X_train.mean()
        X_train, X_test = X_train - mean, X_test - mean
    if with_std:
        std = X_train.std()
        X_train, X_test = X_train / std, X_test / std
    return X_train, X_test
```

## 8. Анализ результатов (ответы на вопросы защиты)

### 8.1 Как масштабирование признаков влияет на качество модели?

При $\text{degree}=1$ масштабирование **не влияет на MAE**: все четыре эксперимента (1–4) дают одинаковые значения MAE_train $\approx 3.42$ и MAE_test $\approx 2.93$.

**Причина:** линейная регрессия со свободным членом инвариантна к линейным преобразованиям признаков. Любое линейное отображение признаков компенсируется изменением весов, предсказания не меняются.

На **число обусловленности** масштабирование влияет существенно:

| Предобработка | $\kappa$ |
|---|---|
| Без предобработки | $2.24 \times 10^8$ |
| Только центрирование | $9.95 \times 10^6$ |
| Только нормировка | $1.16 \times 10^5$ |
| Полная стандартизация | $9.73 \times 10^1$ |

Основной вклад в снижение $\kappa$ вносит **деление на стандартное отклонение**.

### 8.2 Как изменяется качество при увеличении степени полинома?

- $p=1 \to p=2$: MAE_train снижается с $3.42$ до $1.74$, MAE_test — с $2.93$ до $2.56$. Полиномиальные признаки позволяют модели улавливать нелинейные зависимости.

- $p=2 \to p=3$: MAE_train падает до $\approx 10^{-8}$ (фактически 0), но MAE_test взрывается до $663.77$. Это переобучение.

**Причина при $p=3$:** число признаков ($\approx 559$) превышает число объектов обучающей выборки ($\approx 395$). Система СЛАУ недоопределена. МНК находит решение, точно интерполирующее обучающие данные, но не обобщающееся на тест.

### 8.3 Есть ли признаки переобучения?

Переобучение наблюдается при $p=2$ и резко усиливается при $p=3$.

**Признаки переобучения:**

1. **Разрыв между MAE_train и MAE_test:**
   - $p=1$: train $3.42$, test $2.93$ — разрыв мал;
   - $p=2$: train $1.74$, test $2.56$ — разрыв растёт;
   - $p=3$: train $\approx 0$, test $663.77$ — катастрофический разрыв.

2. **Рост числа обусловленности:** $\kappa \sim 10^{17}$ при $p=2$, $\kappa \sim 10^{20}$ при $p=3$ — решение численно нестабильно.

3. **Потеря численной устойчивости при $p=3$:** предсказания принимают значения порядка $10^4$, что видно на scatter-plot.

### 8.4 Как число обусловленности связано с качеством модели?

Число обусловленности $\kappa(X^T X)$ характеризует **чувствительность решения СЛАУ к возмущениям данных**. Если $\kappa \sim 10^k$, то относительная ошибка решения может быть в $10^k$ раз больше относительной ошибки входных данных.

**Связь с качеством:**
- При умеренном $\kappa$ (эксперименты 1–4, $\kappa \leq 10^8$) модель устойчива, MAE_train $\approx$ MAE_test.
- При $\kappa \sim 10^{17}$ (эксп. 5) модель улучшает MAE_test по сравнению с линейной ($2.56 < 2.93$), но уже нестабильна.
- При $\kappa \sim 10^{20}$ (эксп. 6) решение теряет смысл: веса вычислены с огромными ошибками округления.

> **Вывод:** большой $\kappa$ сам по себе не означает плохого MAE — при $p=2$ MAE_test лучше, несмотря на $\kappa \sim 10^{17}$. Однако $\kappa$ является **индикатором риска**: чем он выше, тем менее надёжен результат.

### 8.5 Какая комбинация даёт наилучший результат?

**Эксперимент 5** (`with_mean=True, with_std=True, degree=2`): MAE_test $\approx 2.56$.

- Полиномиальные признаки 2-й степени учитывают нелинейные зависимости;
- Полная стандартизация ограничивает рост $\kappa$ по сравнению с нестандартизованными признаками при $p=2$.
- При этом $\kappa \approx 10^{17}$ — результат получен в условиях пониженной численной устойчивости, что следует учитывать при интерпретации.

## 9. Выводы

1. **Масштабирование при degree=1 не влияет на MAE**, но существенно снижает число обусловленности — с $\sim 10^8$ до $\sim 10^1$ при полной стандартизации. Определяющий вклад вносит деление на стандартное отклонение.

2. **Число обусловленности и масштабирование** характеризуют численную устойчивость решения СЛАУ $X^T X w = X^T y$, а не точность аппроксимации напрямую.

3. **Увеличение степени до 2** снижает MAE на обеих выборках за счёт нелинейных зависимостей. При **degree=3** число признаков превышает число объектов — система недоопределена, что приводит к переобучению: MAE_train $\approx 0$, MAE_test $\approx 664$.

4. **Признаки переобучения:** разрыв MAE_train/MAE_test и рост числа обусловленности при увеличении степени полинома.

5. **Наилучший результат** — `with_mean=True, with_std=True, degree=2` (MAE_test $\approx 2.56$). Комбинация обеспечивает учёт нелинейностей при сохранении приемлемой точности, хотя $\kappa \approx 10^{17}$ остаётся высоким.

## 10. Частые вопросы на защите

**Q: Почему `np.linalg.solve`, а не `np.linalg.inv`?**  
A: `solve` использует LU-разложение и численно устойчивее явного обращения матрицы. Вычисление $A^{-1}$ накапливает дополнительные ошибки округления.

**Q: Почему MAE_train = MAE_test при degree=1 для всех вариантов масштабирования?**  
A: MAE одинаков не только между экспериментами 1–4, но и train ≈ test (3.42 vs 2.93). Инвариантность — почему все 4 эксперимента дают одно и то же значение, а не почему train = test.

**Q: Что значит «инвариантность к линейному преобразованию»?**  
A: Если $X' = aX + b$, то для любых весов $w$ существуют $w'$ такие, что $X'w' = Xw$ при всех $x$. Следовательно, решение нормального уравнения для $X'$ и $X$ даёт одинаковые предсказания.

**Q: Почему `test_indices = indices[:test_size]`, а не `indices[test_size:]`?**  
A: Это авторская реализация разбиения. Первые `test_size` перемешанных индексов — тест, остальные — обучение.

**Q: Почему `std = X_train.std()`, а не `X_train.std(ddof=1)`?**  
A: Использована популяционная дисперсия (делитель $n$, по умолчанию в pandas). Важно применять одни и те же параметры к train и test — и здесь они берутся именно от train.

**Q: Как число признаков меняется с degree?**  
A: При 13 исходных признаках: degree=1 → 13; degree=2 → 104; degree=3 → 559 (без intercept). Формула: $\binom{d+p}{p} - 1$ новых признаков (кроме константы), или $\binom{d+p}{p}$ включая константу.

**Q: Почему в `poly_features` только `range(2, degree+1)`?**  
A: Исходные признаки (степень 1) уже включены через `X_poly = X.copy()`. Цикл добавляет только степени $\geq 2$.

**Q: Что такое число обусловленности геометрически?**  
A: $\kappa(A) = \sigma_{\max}/\sigma_{\min}$ — отношение наибольшего к наименьшему сингулярному числу. Характеризует «вытянутость» эллипсоида, задаваемого матрицей. Чем сильнее вытянут — тем хуже обусловлена система.
