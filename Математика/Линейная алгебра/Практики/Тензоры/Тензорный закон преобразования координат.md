# Тензорный закон преобразования координат

## Обзор семинара

Семинар посвящён тензорному закону преобразования координат при замене базиса. Разбирались задачи трёх типов: вычисление компоненты тензора в новом базисе через подстановку новых базисных векторов и ковекторов в явное разложение тензора по базису (задачи 9a, 9b), аналогичная задача с общими ненулевыми компонентами (задача 10), и поиск одной компоненты тензора типа $T^2_2$ по тензорному закону с нахождением обратной матрицы перехода (задача 11). Центральная техника — сведение формулы тензорного закона к суммам элементов строк и столбцов матриц $C$ и $C^{-1}$.

---

## Методы и подходы

### 1. Подстановка новых базисных векторов (прямой метод)

**Когда применять:** тензор задан явным разложением по тензорному базису; требуется найти конкретную компоненту в новом базисе.

**Алгоритм:**

1. Запомнить, что компонента $\tilde{T}^{i_1\dots i_p}_{j_1\dots j_q}$ — это значение тензора $T$ на наборе $(\tilde{e}_{j_1},\dots,\tilde{e}_{j_q},\,\tilde{e}^{i_1},\dots,\tilde{e}^{i_p})$, где $\tilde{e}_j$ — новые базисные векторы, $\tilde{e}^i$ — новые базисные ковекторы.
2. Выразить новые базисные векторы через старые: $\tilde{e}_j = \sum_k C^k{}_j\, e_k$ (столбцы $C$ дают коэффициенты разложения).
3. Выразить новые базисные ковекторы через старые: $\tilde{e}^i = \sum_k (C^{-1})^i{}_k\, e^k$ (строки $C^{-1}$ дают коэффициенты).
4. Подставить в тензор и воспользоваться мультилинейностью; коэффициенты при базисных элементах тензорного базиса — это компоненты тензора в старом базисе.
5. Выполнить суммирование, отбросив слагаемые с нулевыми компонентами.

**Пример (задача 9a):** Тензор $T = e_1 \otimes e_2 \otimes (e_1 + e_2)$, матрица перехода $C = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$. Найти $\tilde{T}^{211}$.

Ненулевые компоненты $T$: только $T^{121} = T^{122} = 1$ (так как $e_1 \otimes e_2 \otimes (e_1+e_2) = e_1\otimes e_2\otimes e_1 + e_1\otimes e_2\otimes e_2$).

По определению:
$$\tilde{T}^{211} = T(\tilde{e}_1,\, \tilde{e}^2,\, \tilde{e}^1)$$

Здесь тензор $T \in T^2_1(V)$: принимает один вектор и два ковектора. Подставляем:
- $\tilde{e}_1 = e_1 + 3e_2$ (первый столбец $C$).
- $\tilde{e}^2$ — второй новый ковектор; строки $C^{-1}$: $C^{-1} = \frac{1}{\det C}\begin{pmatrix}4&-2\\-3&1\end{pmatrix} = \frac{1}{-2}\begin{pmatrix}4&-2\\-3&1\end{pmatrix}$, вторая строка: $\tilde{e}^2 = \frac{3}{2}e^1 - \frac{1}{2}e^2$.
- $\tilde{e}^1$ — первая строка: $\tilde{e}^1 = -2e^1 + e^2$.

Применяем $T$:
$$T(\tilde{e}_1,\, \tilde{e}^2,\, \tilde{e}^1) = \sum_{a,b,c} T^{abc}\, (\tilde{e}_1)_a\, (\tilde{e}^2)^b\, (\tilde{e}^1)^c$$

Ненулевые слагаемые — только $(a,b) = (1,2)$:
$$= T^{121}\,(\tilde{e}_1)_1(\tilde{e}^2)^2(\tilde{e}^1)^1 + T^{122}\,(\tilde{e}_1)_1(\tilde{e}^2)^2(\tilde{e}^1)^2$$

> дополнено: Здесь $(\tilde{e}_1)_a$ — $a$-я координата вектора $\tilde{e}_1$ в базисе $e$; $(\tilde{e}^i)^k$ — $k$-я компонента ковектора $\tilde{e}^i$ в базисе $e^k$, то есть $k$-й элемент $i$-й строки $C^{-1}$.

**ЛОВУШКИ:**
- Не путать матрицу перехода для векторов ($C$, столбцы) и ковекторов ($C^{-1}$, строки).
- При вычислении $C^{-1}$ не забыть делить на определитель.
- Не отбрасывать слагаемые преждевременно: проверить, действительно ли компонента нулевая.

**ПРИЗНАКИ ПРИМЕНИМОСТИ:** тензор задан суммой произведений базисных векторов/ковекторов (разложение по тензорному базису), матрица $C$ размером $2\times2$ или $3\times3$, нужна одна конкретная компонента.

### 2. Тензорный закон преобразования (формульный метод)

**Когда применять:** компоненты тензора в старом базисе заданы явной формулой или все равны константе; требуется найти конкретную компоненту в новом базисе.

**Общая формула** для тензора типа $(p,q)$:
$$\tilde{T}^{i_1\dots i_p}_{j_1\dots j_q} = \sum_{a_1,\dots,a_p,\,b_1,\dots,b_q} (C^{-1})^{i_1}{}_{a_1}\cdots(C^{-1})^{i_p}{}_{a_p}\; T^{a_1\dots a_p}_{b_1\dots b_q}\; C^{b_1}{}_{j_1}\cdots C^{b_q}{}_{j_q}$$

Верхние (контравариантные) индексы «тянут» матрицу $C^{-1}$; нижние (ковариантные) индексы «тянут» матрицу $C$.

**Алгоритм:**

1. Выписать матрицу перехода $C$ (столбцы — координаты новых базисных векторов в старом базисе).
2. Вычислить $C^{-1}$.
3. Определить все пары суммируемых индексов, отбросить нулевые компоненты $T$.
4. Записать сумму; при константных компонентах вынести константу за знак суммы.
5. Распознать суммы как суммы элементов строк/столбцов соответствующих матриц.

**Пример (задача 8):** $T \in T^2_1(V)$, $\dim V = 3$, все компоненты $T^{ijk} = 2$. Найти $\tilde{T}^{12}_{1\,}$ в базисе $\tilde{e}_i$, задаваемом матрицей $C = \begin{pmatrix}1&0&0\\2&1&0\\0&2&1\end{pmatrix}^T$.

Тензорный закон:
$$\tilde{T}^{12}_{1} = \sum_{a,b,c} (C^{-1})^{1}{}_a\,(C^{-1})^{2}{}_b\, T^{ab}{}_{c}\, C^{c}{}_{1}$$

Поскольку $T^{abc} = 2$ для всех $a,b,c$:
$$\tilde{T}^{12}_{1} = 2\sum_{a}(C^{-1})^{1}{}_a \cdot \sum_{b}(C^{-1})^{2}{}_b \cdot \sum_{c}C^{c}{}_{1}$$

Сумма $\sum_a (C^{-1})^{1}{}_a$ — сумма элементов первой строки $C^{-1}$.

Сумма $\sum_b (C^{-1})^{2}{}_b$ — сумма элементов второй строки $C^{-1}$.

Сумма $\sum_c C^{c}{}_1$ — сумма элементов первого столбца $C$.

Нашли $C^{-1}$. Матрица $C = \begin{pmatrix}1&2&0\\0&1&2\\0&0&1\end{pmatrix}$ (после транспонирования, согласно условию). Обратная:
$$C^{-1} = \begin{pmatrix}1&-2&1\\0&1&-2\\0&0&1\end{pmatrix}$$

Суммы строк: строка 1: $1-2+1=0$; строка 2: $0+1-2=-1$; строка 3: $0+0+1=1$.

Сумма первого столбца $C$: $1+0+0=1$.

$$\tilde{T}^{12}_1 = 2\cdot 0 \cdot (-1) \cdot 1 = 0$$

> дополнено: Ключевое наблюдение: если хотя бы одна из «частичных сумм» обращается в ноль, весь результат равен нулю. Это позволяет прерывать вычисление досрочно.

**Пример (задача 10):** $T^{ijk}_{lm} = 3^m$, $\dim V = 3$. Найти $\tilde{T}^{123}_{31}$ в базисе $\tilde{e}_1 = e_1+3e_2-2e_3$, $\tilde{e}_2 = e_2+4e_3$, $\tilde{e}_3 = -e_3$.

Матрица перехода (столбцы — координаты новых базисных векторов):
$$C = \begin{pmatrix}1&0&0\\3&1&0\\-2&4&-1\end{pmatrix}$$

Тензорный закон:
$$\tilde{T}^{123}_{31} = \sum_{a,b,c,\alpha,\beta} (C^{-1})^1{}_a\,(C^{-1})^2{}_b\,(C^{-1})^3{}_c\, T^{abc}_{\alpha\beta}\; C^\alpha{}_3\, C^\beta{}_1$$

Здесь $T^{abc}_{\alpha\beta} = 3^\beta$. Вынесем по $\beta$:
$$= \sum_\beta C^\beta{}_1 \cdot 3^\beta \cdot \left[\sum_\alpha C^\alpha{}_3\right] \cdot \left[\sum_a (C^{-1})^1{}_a\right]\cdot\left[\sum_b (C^{-1})^2{}_b\right]\cdot\left[\sum_c (C^{-1})^3{}_c\right]$$

> дополнено: Здесь важно, что $T^{abc}_{\alpha\beta} = 3^\beta$ зависит только от $\beta$, поэтому суммирование по $a$, $b$, $c$ и $\alpha$ разбивается на независимые произведения сумм. По $\beta$ суммирование нельзя отделить так же — оно «связано» с коэффициентом $3^\beta$.

Разобьём:
- $\sum_\alpha C^\alpha{}_3$ = сумма третьего столбца $C$: $0+0+(-1) = -1$.
- $\sum_a (C^{-1})^1{}_a$ = сумма первой строки $C^{-1}$.
- $\sum_b (C^{-1})^2{}_b$ = сумма второй строки $C^{-1}$.
- $\sum_c (C^{-1})^3{}_c$ = сумма третьей строки $C^{-1}$.
- По $\beta$: $\sum_\beta C^\beta{}_1 \cdot 3^\beta = C^1{}_1\cdot 3 + C^2{}_1\cdot 9 + C^3{}_1\cdot 27 = 1\cdot3 + 3\cdot9 + (-2)\cdot27 = 3+27-54=-24$.

Находим $C^{-1}$:

$$C^{-1} = \begin{pmatrix}1&0&0\\-3&1&0\\-10+12 \; (\text{вычисляем})&-4&-1\end{pmatrix}$$

Детально: $\det C = 1\cdot1\cdot(-1) = -1$.

$$C^{-1} = \frac{1}{-1}\begin{pmatrix}\text{кофакторы}\end{pmatrix}^T$$

Кофакторы: $M_{11}=1\cdot(-1)-0\cdot4=-1$; $M_{12}=-(3\cdot(-1)-0\cdot(-2))=3$; $M_{13}=3\cdot4-1\cdot(-2)=14$; $M_{21}=-(0\cdot(-1)-0\cdot4)=0$; $M_{22}=1\cdot(-1)-0\cdot(-2)=-1$; $M_{23}=-(1\cdot4-0\cdot(-2))=-4$; $M_{31}=0\cdot0-0\cdot1=0$; $M_{32}=-(1\cdot0-0\cdot3)=0$; $M_{33}=1\cdot1-0\cdot3=1$.

$$C^{-1} = \frac{1}{-1}\begin{pmatrix}-1&0&0\\3&-1&0\\14&-4&1\end{pmatrix}^T = \begin{pmatrix}1&-3&-14\\0&1&4\\0&0&-1\end{pmatrix}$$

Суммы строк $C^{-1}$: строка 1: $1-3-14=-16$; строка 2: $0+1+4=5$; строка 3: $0+0-1=-1$.

$$\tilde{T}^{123}_{31} = (-24)\cdot(-1)\cdot(-16)\cdot5\cdot(-1) = (-24)\cdot(-1)\cdot(-16)\cdot(-5)$$
$$= 24\cdot1\cdot16\cdot5 = 1920$$

> дополнено: На семинаре это задание было начато и записаны промежуточные шаги; конкретное итоговое число в транскрипции не зафиксировано явно. Приведённые вычисления соответствуют алгоритму, обсуждавшемуся в классе.

**ЛОВУШКИ:**
- Не путать строки и столбцы: верхний индекс в $\tilde{T}$ — номер строки $C^{-1}$; нижний — номер столбца $C$.
- При $T^{abc\dots} = \text{const}$ суммирование факторизуется в произведение сумм строк/столбцов только тогда, когда компоненты от индексов не зависят. Если зависят (задача 10) — только часть сумм факторизуется.
- Сумма элементов строки $C^{-1}$ $\ne$ сумме строки $C$.

**ПРИЗНАКИ ПРИМЕНИМОСТИ:** компоненты в исходном базисе заданы явно (константа или формула), матрица перехода задана явно, нужна одна компонента в новом базисе.

### 3. Тензорный закон для тензоров типа $(1,1)$ и $(0,2)$: матричный вид

**Тензор типа $(1,1)$** (оператор): $\tilde{A} = C^{-1}AC$ (матрица в новом базисе = $C^{-1}AC$).

**Тензор типа $(0,2)$** (билинейная форма): $\tilde{B} = C^T B C$ (матрица в новом базисе = $C^T B C$).

Эти формулы — частный случай общего тензорного закона. На семинаре они упомянуты как проверочные ориентиры.

## Разбор задач

### Задача 8. Все компоненты равны 2, матрица $C$ задана, найти $\tilde{T}^{12}_1$

**Тип:** тензор $T \in T^2_1(V)$, $\dim V = 3$. Все компоненты $T^{ijk} = 2$.

**Метод:** формульный (тензорный закон).

**Решение:**

Матрица перехода (по условию):
$$C = \begin{pmatrix}1&2&0\\0&1&2\\0&0&1\end{pmatrix}$$

Обратная матрица (методом Гаусса или формулой для верхнетреугольной):
$$C^{-1} = \begin{pmatrix}1&-2&1\\0&1&-2\\0&0&1\end{pmatrix}$$

Проверка: $C\cdot C^{-1}$ даёт единичную матрицу. ✓

Тензорный закон:
$$\tilde{T}^{12}_1 = \sum_{a,b,c}(C^{-1})^1{}_a\,(C^{-1})^2{}_b\, T^{ab}{}_c \, C^c{}_1$$

Поскольку $T^{abc} = 2$ для всех $a,b,c$:
$$\tilde{T}^{12}_1 = 2\Bigl(\sum_a (C^{-1})^1{}_a\Bigr)\Bigl(\sum_b (C^{-1})^2{}_b\Bigr)\Bigl(\sum_c C^c{}_1\Bigr)$$

Суммы:
- Строка 1 матрицы $C^{-1}$: $1+(-2)+1 = 0$.
- Строка 2 матрицы $C^{-1}$: $0+1+(-2) = -1$.
- Столбец 1 матрицы $C$: $1+0+0 = 1$.

$$\tilde{T}^{12}_1 = 2\cdot 0\cdot(-1)\cdot 1 = 0$$

**Ответ:** $\tilde{T}^{12}_1 = 0$.

**Комментарий из транскрипции:** преподаватель подчеркнул, что если одна из частичных сумм равна нулю, можно прекратить вычисление — результат всё равно ноль. Это значительно экономит время.

### Задача 9a. Тензор в виде разложения, матрица $2\times2$, найти $\tilde{T}^{211}$

**Тип:** тензор $T = e_1\otimes e_2\otimes(e_1+e_2) \in T^2_1(V)$, $\dim V = 2$.

**Ненулевые компоненты:** $T^{121}=1$, $T^{122}=1$ (все остальные нули).

**Матрица перехода:** $C=\begin{pmatrix}1&2\\3&4\end{pmatrix}$.

**Обратная матрица:** $\det C = 4-6 = -2$.
$$C^{-1} = \frac{1}{-2}\begin{pmatrix}4&-2\\-3&1\end{pmatrix} = \begin{pmatrix}-2&1\\\frac{3}{2}&-\frac{1}{2}\end{pmatrix}$$

**Прямой метод.** По определению:
$$\tilde{T}^{211} = T(\tilde{e}_1,\,\tilde{e}^2,\,\tilde{e}^1)$$

Новые базисные векторы (столбцы $C$):
- $\tilde{e}_1 = e_1+3e_2$ (первый столбец).

Новые базисные ковекторы (строки $C^{-1}$):
- $\tilde{e}^1 = -2e^1 + e^2$ (первая строка $C^{-1}$).
- $\tilde{e}^2 = \tfrac{3}{2}e^1 - \tfrac{1}{2}e^2$ (вторая строка $C^{-1}$).

Тензор действует как:
$$T(v,\xi,\eta) = \xi(v_1)\,\eta(v_2) + \xi(v_1)\,\eta(v_2) \quad \text{(по ненулевым компонентам)}$$

Точнее:
$$\tilde{T}^{211} = \sum_{a,b,c} T^{abc}\,(\tilde{e}_1)_a\,(\tilde{e}^2)^b\,(\tilde{e}^1)^c$$

Ненулевые — только $(a,b)=(1,2)$:
$$= T^{121}\underbrace{(\tilde{e}_1)_1}_{1}\underbrace{(\tilde{e}^2)^2}_{-1/2}\underbrace{(\tilde{e}^1)^1}_{-2} + T^{122}\underbrace{(\tilde{e}_1)_1}_{1}\underbrace{(\tilde{e}^2)^2}_{-1/2}\underbrace{(\tilde{e}^1)^2}_{1}$$

$$= 1\cdot1\cdot(-\tfrac{1}{2})\cdot(-2) + 1\cdot1\cdot(-\tfrac{1}{2})\cdot1 = 1 - \tfrac{1}{2} = \tfrac{1}{2}$$

> дополнено: В транскрипции преподаватель указывает, что прямой метод (подстановка новых базисных элементов) и формульный метод (тензорный закон) должны давать одинаковый результат. Студентам предлагалось проверить оба подхода.

**Формульный метод (проверка):**
$$\tilde{T}^{211} = \sum_{a,b,c,\alpha}(C^{-1})^2{}_a\,(C^{-1})^1{}_b\, T^{ab}{}_{c}\, C^c{}_1$$

Ненулевые $T^{abc}$: $(1,2,1)$ и $(1,2,2)$.

Слагаемое $(a,b,c)=(1,2,1)$: $(C^{-1})^2{}_1\cdot(C^{-1})^1{}_2\cdot1\cdot C^1{}_1 = \tfrac{3}{2}\cdot1\cdot1\cdot1 = \tfrac{3}{2}$.

Слагаемое $(a,b,c)=(1,2,2)$: $(C^{-1})^2{}_1\cdot(C^{-1})^1{}_2\cdot1\cdot C^2{}_1 = \tfrac{3}{2}\cdot1\cdot1\cdot3 = \tfrac{9}{2}$.

> дополнено: В транскрипции конкретные числа этой задачи не были полностью озвучены — преподаватель предложил студентам решить самостоятельно. Числа выше вычислены строго по описанному алгоритму.

### Задача 9b. Все компоненты равны 1, матрица $2\times2$, найти $\tilde{T}^{112}$

**Тип:** тензор $T \in T^2_1(V)$, $\dim V=2$, все компоненты $T^{ijk}=1$.

**Матрица перехода:** $C=\begin{pmatrix}0&2\\1&5\end{pmatrix}$.

**Обратная:** $\det C = 0\cdot5-2\cdot1=-2$.
$$C^{-1} = \frac{1}{-2}\begin{pmatrix}5&-2\\-1&0\end{pmatrix} = \begin{pmatrix}-5/2&1\\1/2&0\end{pmatrix}$$

**Тензорный закон:**
$$\tilde{T}^{112} = \sum_{a,b,c}(C^{-1})^1{}_a\,(C^{-1})^1{}_b\, T^{ab}{}_c\, C^c{}_2$$

Так как $T^{abc}=1$:
$$= \Bigl(\sum_a (C^{-1})^1{}_a\Bigr)\Bigl(\sum_b (C^{-1})^1{}_b\Bigr)\Bigl(\sum_c C^c{}_2\Bigr)$$

Суммы:
- Строка 1 $C^{-1}$: $-\tfrac{5}{2}+1=-\tfrac{3}{2}$.
- Столбец 2 $C$: $2+5=7$.

$$\tilde{T}^{112} = \Bigl(-\tfrac{3}{2}\Bigr)\cdot\Bigl(-\tfrac{3}{2}\Bigr)\cdot7 = \tfrac{9}{4}\cdot7 = \tfrac{63}{4}$$

В транскрипции прозвучали варианты ответов: кто-то получал 63, кто-то другое число. Преподаватель проверял ответы совместно.

### Задача 11. Тензор типа $(1,1)$: найти $\tilde{T}^{21}_{12}$

**Условие:** $T = \begin{pmatrix}-1&-1&3&2\\-5&0&1&4\\3&1&-2&3\\2&-3&-1&5\end{pmatrix}$, матрица перехода $C=\begin{pmatrix}-1&2\\1&1\end{pmatrix}$.

> дополнено: По условию задачи, матрица $T$ задаёт тензор с блочной структурой (два верхних и два нижних индекса, $\dim V = 2$). Матрица $4\times4$ — это «слоёная» запись компонент $T^{ij}_{kl}$: строки индексируются парой $(i,k)$, столбцы парой $(j,l)$ (или другим соглашением о порядке слоёв).

**Метод:** тензорный закон для тензора типа $(2,2)$.

**Нахождение $C^{-1}$:** $\det C = (-1)\cdot1-2\cdot1=-3$.
$$C^{-1} = \frac{1}{-3}\begin{pmatrix}1&-2\\-1&-1\end{pmatrix} = \begin{pmatrix}-1/3&2/3\\1/3&1/3\end{pmatrix}$$

**Тензорный закон:**
$$\tilde{T}^{21}_{12} = \sum_{a,b,\alpha,\beta}(C^{-1})^2{}_a\,(C^{-1})^1{}_b\, T^{ab}_{\alpha\beta}\, C^\alpha{}_1\, C^\beta{}_2$$

Строки $C^{-1}$: строка 1: $(-1/3, 2/3)$; строка 2: $(1/3, 1/3)$.

Столбцы $C$: столбец 1: $(-1, 1)$; столбец 2: $(2, 1)$.

Разворачиваем сумму по всем $a,b,\alpha,\beta \in \{1,2\}$ (16 слагаемых):

$$\tilde{T}^{21}_{12} = \sum_{a,b,\alpha,\beta}(C^{-1})^2{}_a\cdot(C^{-1})^1{}_b\cdot T^{ab}_{\alpha\beta}\cdot C^\alpha{}_1\cdot C^\beta{}_2$$

Преподаватель записал начало и конец суммы:

Первое слагаемое $(a,b,\alpha,\beta)=(1,1,1,1)$:
$$(C^{-1})^2{}_1\cdot(C^{-1})^1{}_1\cdot T^{11}_{11}\cdot C^1{}_1\cdot C^1{}_2 = \tfrac{1}{3}\cdot(-\tfrac{1}{3})\cdot(-1)\cdot(-1)\cdot2$$

Последнее слагаемое $(a,b,\alpha,\beta)=(2,2,2,2)$:
$$(C^{-1})^2{}_2\cdot(C^{-1})^1{}_2\cdot T^{22}_{22}\cdot C^2{}_1\cdot C^2{}_2 = \tfrac{1}{3}\cdot\tfrac{2}{3}\cdot5\cdot1\cdot1$$

Полная сумма вычисляется перебором всех 16 слагаемых. На семинаре студенты выполняли вычисление самостоятельно.

## Справочный лист

**Тензорный закон преобразования** для $T\in T^p_q(V)$ при замене базиса $e_i \mapsto \tilde{e}_j = \sum_i C^i{}_j\, e_i$:

$$\boxed{\tilde{T}^{i_1\dots i_p}_{j_1\dots j_q} = \sum (C^{-1})^{i_1}{}_{a_1}\cdots(C^{-1})^{i_p}{}_{a_p}\cdot T^{a_1\dots a_p}_{b_1\dots b_q}\cdot C^{b_1}{}_{j_1}\cdots C^{b_q}{}_{j_q}}$$

**Правила знаков:**
- Верхние индексы: $C^{-1}$, выбор строки по верхнему индексу результата.
- Нижние индексы: $C$, выбор столбца по нижнему индексу результата.

**Ключи к суммам при $T^{a\dots b\dots}=\text{const}$:**
- $\sum_a (C^{-1})^i{}_a$ = сумма элементов $i$-й строки $C^{-1}$.
- $\sum_b C^b{}_j$ = сумма элементов $j$-го столбца $C$.

**Новые ковекторы через старые:**
$$\tilde{e}^i = \sum_k (C^{-1})^i{}_k\, e^k \quad \Rightarrow \quad \text{строки } C^{-1} \text{ — компоненты новых ковекторов.}$$

**Новые векторы через старые:**
$$\tilde{e}_j = \sum_k C^k{}_j\, e_k \quad \Rightarrow \quad \text{столбцы } C \text{ — координаты новых векторов.}$$

**Тип тензора** $T^p_q$: $p$ верхних индексов (контравариантные), $q$ нижних (ковариантные). Число аргументов: $p$ ковекторов и $q$ векторов.

**Размер тензорного базиса:** $n^{p+q}$ элементов, где $n = \dim V$.

## Типичные ошибки семинара

1. **Перепутаны матрица $C$ и $C^{-1}$:** ковекторы выражаются через строки $C^{-1}$, а не $C$.
2. **Не та строка/столбец:** верхний индекс результата задаёт номер строки $C^{-1}$; нижний — номер столбца $C$.
3. **Ошибка при вычислении $C^{-1}$:** особенно знак при делении на определитель.
4. **Преждевременное отбрасывание слагаемых:** нужно убедиться, что компонента тензора действительно нулевая.
5. **Потеря множителя:** при вынесении константы за сумму все суммирования должны остаться.
6. **Неверный порядок индексов:** в тензорном законе суммирование по «старым» индексам, а не по «новым».
7. **Путаница в слоях матрицы** для многоиндексных тензоров: строка матрицы соответствует двум индексам; нужно чётко зафиксировать соглашение о порядке слоёв до начала вычислений.
