# Гайд к КР — ЛП, двойственность, Лагранж

Темы КР: графический метод, двойственная задача, симплекс-таблица, метод множителей Лагранжа.
Связанные конспекты: [[Графический метод решения ЗЛП и двойственные задачи]], [[Симплекс-разности и правила выбора разрешающего элемента]], [[Двойственность в линейном программировании]].

## 1. Графический метод

**Когда:** 2 переменные (или после Гаусса осталось 2 свободные).

1. Каждое ограничение → прямая (по точкам пересечения с осями).
2. Полуплоскость: подставить $(0,0)$ (если прямая через начало — другую точку).
3. Область = пересечение всех полуплоскостей и $x,y\ge0$. **Рисовать прямые целиком** — вершина может быть далеко (в ДЗ была $(15,12)$).
4. Градиент $\nabla f = (c_1,c_2)$. Линия уровня $\perp$ градиенту.
   - max: двигать **по** градиенту до последней точки касания;
   - min: **против** градиента.
5. Координаты вершины — **решением системы** двух прямых, не на глаз.
6. Проверка/альтернатива: посчитать $f$ во всех вершинах.

**Особые случаи:** линия уровня параллельна стороне → оптимален весь отрезок; область неограничена по градиенту → $f\to\infty$ (при этом другой экстремум может существовать); область пуста → несовместно.

**Пример (ДЗ):** $x-2y$, $6x+3y\ge30$, $x-y\le3$, $-3x+5y\le15$. Начало координат **не** в области. Треугольник с вершинами $(\tfrac{13}3,\tfrac43)$, $(\tfrac{35}{13},\tfrac{60}{13})$, $(15,12)$. $\max=\tfrac53$, $\min=-9$.

## 2. Симплекс-метод

### 2.1. Подготовка

| Ситуация | Что делать |
|---|---|
| min | $g=-f\to\max$; в конце $f^*=-g^*$ |
| $x\ge a$ | $x=x'+a$ во **всех** строках и в цели (коэфф. множит сдвиг!) |
| $x\le0$ | $x=-x'$ |
| $x$ свободная | $x=x^+-x^-$ |
| $\le$, $b\ge0$ | $+s_i$ (slack в базис) |
| $\ge$, $b\le0$ | умножить на $-1$ → $\le$ |
| $\ge$, $b>0$ | искусственный базис (М-метод / 2 фазы) — на семинаре только начинали |
| $=$ | выбрать базисную переменную, Гаусс |

**Выбор базисной переменной для равенства:** положительный коэффициент в равенстве, $\le0$ в остальных строках. После Гаусса проверить **$b\ge0$ во всех строках**.

**Сколько базисных:** = числу строк. Свободных = (все переменные **со slack**) − строки.

### 2.2. Таблица

- Строка $(a_1,\dots\mid b)$ означает $a_1x_1+\dots=b$. Для $z$: $z + a_1x_1+\dots = b$.
- Стартовая строка $z$: $z - c^\top x = 0$ → коэффициенты $-c_j$.
- **Обнулить строку $z$ под всеми базисными столбцами.**
- Базисные столбцы = единичная матрица (в любом порядке), включая $0$ в строке $z$.

### 2.3. Итерация (max)

1. **Стоп**, если в строке $z$ все числа $\ge0$ → оптимум.
2. **Столбец:** самое отрицательное число строки $z$.
3. **Строка:** $\min\ b_i/a_{ik}$ только по $a_{ik}>0$. Нет таких → $f$ не ограничена.
4. **Пересчёт:**
   - ведущую строку делим на ведущий элемент → $R$;
   - каждую другую (и $z$): $\text{новая}=\text{старая}-a\cdot R$, где $a$ — её элемент в ведущем столбце. **Всегда минус**, «плюс» возникает сам при $a<0$.
5. Проверки после таблицы:
   - ведущий столбец $=(0,\dots,1,\dots,0)$;
   - $b\ge0$ во всех строках-ограничениях;
   - $b_z$ = значение цели в текущей вершине, $b_z$ не убывает.

**Чтение ответа:** базисные = $b$ своей строки, остальные $=0$. $z^*=b_z$. Подставить в **исходные** ограничения.

**Особые исходы:** $0$ в строке $z$ у свободной переменной → альтернативный оптимум. Ничья в тесте отношений → вырожденность (при зацикливании — правило Бланда: наименьший индекс).

### 2.4. Смысл

- Свободные $=0$ ⇔ стоим на соответствующих «стенках»; вершина = пересечение $n$ стенок.
- Строка $z$ ⇔ $z = z_0 - \sum d_j x_j^{\text{своб}}$: отрицательный коэффициент в таблице = рост переменной увеличивает $z$.
- Критерий оптимальности глобальный: $z = z_0 - (\ge0)\le z_0$ для любой допустимой точки.
- В финальной таблице под slack-столбцами в строке $z$ — решение двойственной $u^*$.

## 3. Двойственная задача

**Базовый случай:** $\max c^\top x,\ Ax\le b,\ x\ge0 \;\leftrightarrow\; \min b^\top u,\ A^\top u\ge c,\ u\ge0$.

**Механика:**
- строка (ограничение) $i$ прямой → переменная $u_i$;
- столбец (переменная) $x_j$ прямой → ограничение $j$: $(\text{столбец }j)\cdot u \ ? \ c_j$;
- $b$ → цель, $c$ → правые части, max ↔ min.

**Знаки.** «Нормальное» неравенство: для **max** это $\le$, для **min** это $\ge$.

| Прямая | Двойственная |
|---|---|
| нормальное неравенство | $u_i\ge0$ |
| ненормальное неравенство | $u_i\le0$ |
| равенство | $u_i$ любого знака |
| $x_j\ge0$ | нормальное неравенство (своей задачи) |
| $x_j\le0$ | ненормальное |
| $x_j$ свободная | равенство |

**Безопасный путь:** привести все неравенства к нормальному виду (умножение строки **и** $b_i$ на $-1$) → все $u\ge0$.

**Самопроверка:** коэффициент при $u_i$ в $j$-м ограничении двойственной = коэффициент при $x_j$ в $i$-м ограничении прямой.

**Теоремы:** слабая $c^\top x\le b^\top u$; сильная $c^\top x^*=b^\top u^*$. Прямая неограничена ⇒ двойственная несовместна.

## 4. Метод множителей Лагранжа

1. $L = f - \sum\lambda_i\varphi_i$.
2. $L_{x_j}=0$, $\varphi_i=0$.
3. Решить систему. **Разбирать случаи**, не делить на то, что может быть $0$; не терять $\pm$ при корнях.
4. Для каждой точки (со **своим** $\lambda$):
   - $d^2L$ по $x$ при фиксированном $\lambda$;
   - связь на приращения: $d\varphi=0$ → выразить одно $dx_k$ через остальные и подставить;
   - знак формы от оставшихся приращений:
     - $<0$ при всех $h\ne0$ (отриц. **определена**) → max;
     - $>0$ при всех $h\ne0$ → min;
     - знакопеременна (показать два направления с разными знаками) → не экстремум;
     - только полуопределена (обнуляется на ненулевом $h$) → теорема ответа не даёт.
5. Знак формы: выделение полного квадрата или Сильвестр по **матрице формы**.
6. Глобальность: ограничение компактно (окружность, сфера) → глобальные экстремумы есть, можно сравнить $f$ в точках. Неограничено (плоскость) → только локальные.

**Примеры:**
- $4xy$, $x^2+y^2=r^2$: $\lambda=\pm2$, **по 2 точки** на каждое; $\max=2r^2$ в $\pm(\tfrac r{\sqrt2},\tfrac r{\sqrt2})$, $\min=-2r^2$.
- $x+2y$, $x^2+y^2=5$: $d^2L=-2\lambda(dx^2+dy^2)$; $\max=5$ в $(1,2)$, $\min=-5$ в $(-1,-2)$.
- $xyz$, $x+y+z=3$: $(1,1,1)$ — лок. max ($d^2L=-2(dy^2+dydz+dz^2)<0$); $(3,0,0)$ и перестановки — не экстремумы ($6\,dy\,dz$); глобальных нет.
